pe74 cycle 2: RESTORATION AUDIT. Every B-grade result re-run in three versions (6 Oct 2026).
Versions: all = every token (old corpus, editor's restorations counted as read); rd = read + damaged ('?' signs become 'x', '[..]' and '<..>' signs removed, a line that loses a '?' or restored numeral is marked lacuna); r = read only (damaged '#' tokens also dropped). The rd and r versions drop 8.8% / 22% of sign tokens and 2.2% / 16% of numerals.
Method: wherever possible the ORIGINAL loop code was run unchanged through tools/pe74_harness.py (corpus file swapped, checkpoints redirected to data/pe74_ckpt/<mode>/): pe59_cycle1 (pe74_c2_pe59.py), pe69_c2 (pe74_c2_pe69.py), pe70_c1b (pe74_c2_pe70.py), pe72 decoder with the FROZEN v1/v2 readings (pe74_c2_pe72.py), pe66_c1 L/O and pe66_c3 D2/V2 (pe74_c2_pe66.py). Short re-implementations for pe42, pe63, pe71 and test d (pe74_c2_misc.py). Every 'all' run reproduces the published numbers exactly (pe59 6.304 vs 6.371 bits, 18/101 totals; pe69 34/49 vs 5.45; pe70 58 vs 39.6, LOVO 0.667; pe72 v1 93, v2 104; pe71 24/34 vs 13.17; pe42 7/36; pe66 rows identical), which calibrates the harness.
Controls (pe74_c2_ctrl.py): (1) PLANTED: a fake sign planted on 92 restored-or-uncertain closing-line tokens plus 12 read decoys. (2) RANDOM THINNING: the same numbers of tokens dropped at random positions (50 draws per version).
