# pe43 cycle 1: THE SIGNS EVOLVE LIKE A FAMILY TREE, AND THE TREE IS THE DICTIONARY. Does the form tree (variant -> base, compound -> parts) carry meaning families?
# Scripts tools/pe43_common.py, pe43_search.py, pe43_cycle1.py. Checkpoints data/pe43_ckpt/c1_{PE,PC,PLANT}.json, logs c1_*.log.
# Prior art (web search): C. Skelton (Penn) built phylogenies of tablet DEPOSITS from variants of one sign (EN~a) in proto-cuneiform, and of Linear B scribes; nobody has treated the forms themselves as a population whose tree branches are meaning families. Not in LITERATURE.md, FINDINGS.md or STRATEGIES.md (pe19 seriated tablets; pe22 counted variants; pe41 simulated variant coining).
# Answer key for the control: proto-cuneiform (PC) lexical lists read straight from the CDLI ATF (catalogue subgenre = list): a root is labelled with a list family only if >= 60% of its >= 3 lexical tokens sit in one list (190 roots; 158-161 also on >= 4 admin tablets: PERSONS 57, WOOD 19, PLACES 18, METAL 17, VESSELS 16, TRIBUTE 16, ANIMALS 6, FISH 5, GRAIN 4, BIRDS 2, PLANTS 1).
# Contexts (no interpretation): SYS = rarest numeral code on the same line; POS = header / sole / first / middle / last x obverse / reverse.
