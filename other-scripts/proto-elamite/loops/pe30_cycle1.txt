pe30 cycle 1 -- "what the totals leave out": controls for the exclusion-rule search
Tools: tools/pe30_common.py, pe30_ur3.py, pe30_cycle1.py. Numbers: data/pe30_cycle1.json. Cases: data/pe30_ckpt/ (git-ignored).
Cases: tier 1 = the 49 clean pe24 tablets (23 close with all entries +1); tier 2 adds 42 damaged tablets whose every numeral is readable (sign damage and restored numerals allowed; a lost entry numeral, a broken/missing state line or a line-number gap excludes the tablet). Tier 1+2 = 91 tablets, 33 close at baseline.
Rule families (global, one rule for all tablets): EX(f) leave out entries with feature f; EX(f|g) leave out f or g; KEEP(f) sum only f; C(c) add a constant c N01 (c = +-1,2,3,5,10; count totals); EX(f)+C(c). Features: position (first, second, penult, last, first/last column), every sign token, base sign, first/last sign, variant marker, sign count (bare, 1, 2, 3+), numeral unit, number system, size (largest, smallest, one unit, more than half), duplicates (same signs / same value as another entry), damage / restored, relation to the total line (shares a sign, same final sign, none). Tier 1: 272 features, 40,131 rules; tier 1+2: 437 features, 100,521 rules. Fit = most closures on a random half (ties: simplest family, averaged), scored on the other half (100 splits).
