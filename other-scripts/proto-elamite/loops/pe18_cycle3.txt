pe18 cycle 3 (4 Oct 2026): MASSIVE RANDOM SEARCH - what predicts a tablet's number system beyond its goods?
Tools: tools/pe18_cycle3.py. Numbers: data/pe18_ckpt/c3.json, c3.log, c3_search_*.json (git-ignored).
Target: main non-ambiguous system of 865 Susa tablets (C 462, DEC 140, SEX 114, FRAC 53, C@ 32, N23 29, S@ 23, B 12). 355 features: GOODS (44 class signs, the pe6-style baseline), HDR 26, VOC 150, VAR 120 variant forms, FMT 9, SITE 5 plateau-likeness scores, SEAL. Multinomial logistic regression. Search on 60% of tablets (5-fold CV), 40% reserve frozen. Score = bits per tablet saved by goods + set over goods alone.

| ID | Method and control | Result | Verdict |
|---|---|---|---|
| PE-18.3a | Whole families added to goods, trained on search half, scored on reserve; null = labels permuted within size bin x capacity flag x dominant class sign on the reserve (200x) | goods alone 2.06 bits (CV). Gain on reserve: FMT +0.060 (null -0.090, p 0.005), SITE +0.015 (null -0.031, p 0.005); HDR, VOC, VAR, SEAL at or below null (large families overfit: VOC -0.99, VAR -0.77, null similar) | Only tablet format and plateau-likeness add to goods; the SITE gain is tiny (0.015 bits per tablet) |

| PE-18.3c | PLANTED: a real variant form (3-8% prevalence) switched on in 30% of DEC tablets; same search | 61 sets above FWER (6 more than real); sets containing the planted feature gain +0.018 vs -0.039 without; 3 of the top 10 contain it | PASS: the search sees a planted 'scribal accent' carried by one variant form on 30% of DEC tablets |

| PE-18.3f | TRANSFER to 34 plateau tablets with a system label (C 17, DEC 8, SEX 4, N23 3, C@ 2), models trained on all Susa | prior 2.13 bits; goods 2.54; goods + best format set 2.33; goods + SITE 2.83; goods + all 3.66 | Susa's goods-to-system habits do NOT transfer: the plateau tablets are predicted worse than by the class frequencies alone. The plateau uses the same systems for (partly) different goods |
| PE-18.3 | Cycle verdict | Nothing about who wrote or for whom (variants, headers, vocabulary, plateau-likeness, seal) predicts the number system beyond the goods, except a tiny SITE gain (+0.015 bits) and format (+0.06 bits, likely a visibility artefact) | Grade B (negative): number-system choice at Susa is not predicted by scribal fingerprints; the pe6 'system follows the tablet' effect is not a hidden scribe or counterparty signature in any of 355 features.
