PE7 cycle 1 ("names as DNA"): are deduplicated PE entry middles tree-like?
Tools: tools/pe7_build.py (corpora -> data/pe7_corpora.json), pe7_common.py (edit model, NJ, delta, Fitch parsimony with SPR search + restarts, MCMC), pe7_cycle1.py, pe7_sum1.py. Data: data/pe7_cycle1.json, .log, checkpoints data/pe7_ckpt/c1_*.
Corpora (200 distinct names per replicate, 6 replicates, each vs 2 shuffled-element nulls = tokens permuted across names, lengths kept):
PE = random distinct multi-sign middles (1,298 types); PE_tab = whole-tablet cluster sample; UR3_SEAL / OB_SEAL = seal owners (CDLI dump); UR3_PAT / OB_PAT = 100 father+son pairs from seal patronymics (2,585 / 909 pairs); CN_FULL = Chinese full names, 40 surnames x 5; LINB = Linear B personnel names (DAMOS); RAND = iid strings with PE sign frequencies.
Statistics: delta = mean quartet delta score (lower = more tree-like); RI / CI of the best Fitch tree on element-presence characters (NJ start + 5 random starts, SPR hill climbing); MCMC (SPR moves, exp(-L/0.5)) mean posterior support of best-tree clades.

| ID | Method and control | Result | Verdict |
|---|---|---|---|
| PE-1.1 | Tree-likeness, real minus shuffled-element null (6 reps): RI excess / delta drop / clade-support excess | RAND +0.005 / +0.002 / -0.003 (null works); LINB +0.021 / -0.002 / +0.030; PE +0.024 / -0.024 / +0.014; PE_tab +0.041 / -0.034 / +0.022; UR3_SEAL +0.103 / -0.014 / +0.059; OB_SEAL +0.110 / -0.011 / +0.082; UR3_PAT +0.097; OB_PAT +0.119; CN_FULL +0.167 | PE names carry a little tree signal (RI z 3.6), at the Linear B level, ~1/4 of Sumerian/Akkadian name lists and ~1/7 of surname-structured names |
| PE-1.2 | Does family structure add tree signal? Father+son samples vs unrelated seal owners of the same period | UR3_PAT RI excess 0.097 vs UR3_SEAL 0.103; OB_PAT 0.119 vs OB_SEAL 0.110; clade support likewise equal | tree-likeness in Mesopotamian names comes from the shared name-element lexicon (compounding), NOT from kinship: test (1) alone cannot detect lineage; tests (2)-(3) are needed |
| PE-1.3 | Cluster sample (whole tablets) vs random sample of PE names | RI excess 0.041 vs 0.024; delta drop 0.034 vs 0.024; support 0.022 vs 0.014 | names written on the same tablet raise tree signal: co-tablet similarity exists (tested directly in cycle 2) |
| PE-1.4 | Fitted mutation spectrum (hard-EM stochastic edit model, nearest-neighbour alignments, match/sub/indel) | PE 0.39/0.31/0.30 (indel total); Ur III 0.46-0.50/0.30-0.32/0.20-0.22; OB 0.46-0.48/0.34-0.36/0.16-0.20; LINB 0.47/0.26/0.26; RAND 0.38/0.29/0.34; CN 0.35/0.65/0 | PE nearest neighbours are as far apart as random strings (match share 0.39 vs 0.38 random, 0.46+ in real name lists): PE middles are not built from a small stock of recurring name elements |

Cycle verdict: PE middles are weakly tree-like (beyond shuffling, z ~3.6) but far below element-compounding name systems; the positive controls show that tree-likeness reflects a shared element lexicon, not families. Lineage questions move to clade-label tests (cycle 2).
