PE-56 cycle 1: HIRE FORGERS AND WATCH WHERE THEY FAIL (item-level forger inversion, Proto-Elamite)
Date 5-6 Oct 2026. Scripts: tools/pe56_common.py (corpora, relations, forger ensemble, contest, controls),
tools/pe56_c1.py, tools/pe56_report1.py. Checkpoints data/pe56_ckpt/c1_*.json (git-ignored).
Novelty check: no PE forger-residue study in LITERATURE.md, FINDINGS.md, STRATEGIES.md or a web search (PE ML work
is sign prediction / tablet-type classification). x4 ran document-level forgery AUCs; la46 ran this inversion on
Linear A. pe56 adapts la46 to PE's line structure (header lines, entries = sign string + numeral with system and
value) and adds new forger families.
Corpus: 1,178 PE tablets with >= 2 numeral lines (20,356 tokens; base sign forms; values from pe47 pe_value).
Relations (presence per tablet; 14 families): ES/EF last/first sign of entry i -> entry i+1; LR sign in an entry ->
sign in an entry >= 2 entries later; HE header sign -> entry sign; HS header sign -> number system on the tablet;
SP two systems on one tablet; SO system succession; SN/SM last sign -> system / magnitude; MM magnitude succession;
TOT line = running sum of >= 2 earlier entries of the same system; CO two signs on non-adjacent lines; LAST sign
on last line; WP adjacent sign pair. Long-range families use signs on >= 8 tablets.
Forgers: 120 random architectures per corpus, 5-fold CV, 1 forgery per held-out tablet per architecture (141,000
forged tablets per corpus, ~1.5 M in all). Families: (a) back-off n-grams (order 1-5) over randomly abstracted
streams (rare signs merged, numerals as system+bin / system / kind / coarse), optional site, line index, tf-idf
tablet clusters K 2-32 (vocabulary-clustering forgers), copied layout templates, line reset; (b) entry-level
grammars: line banks per cluster with Markov succession on the previous entry's last sign, numerals copied or
re-drawn given the last sign, real or borrowed headers; (c) bag forgers (entries dealt at random from the
cluster's pool into a real skeleton). Rule (la46 cycle 3): ensemble-mean expectation E, residue p =
P(Poisson(E) >= R), R = real held-out tablets with the relation. Thresholds 1e-3 and Bonferroni (0.05 / tested).
Nulls: W1 (n-gram k3 + K16 + template world), W2 (line-bank Markov world), SH1/SH2 (signs shuffled globally,
layout and numerals kept). Positive: PL1/PL2 = W1/W2 worlds with 8 planted long-range constraints (4 ordered
sign -> sign >= 2 entries later, 2 header -> entry sign, 2 header -> number system; rate 0.8). Real-world
controls, sign identities only, sampled to PE token count: PC (proto-cuneiform, CDLI), UR (Ur III, CDLI).
