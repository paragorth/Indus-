pe8 cycle 1 -- "the tablets were filled-in forms": how many forms?  (tools/pe8_common.py, pe8_build.py, pe8_cycle1.py;
numbers data/pe8_cycle1.json, .log; metadata data/pe8_meta.json from CDLI catalogue museum_no / excavation_no / findspot)
Skeleton = 15 role features per tablet, names and quantities blanked: header type (none / M157 / M327-family / other),
header length, entry number-system profile (S/C/CS/F/B/O), entry count bin, one-sign-entry share, class-sign-final share,
class sign repeated, prefix used, bare numeral line, subscript line, reverse use (blank/total/entries/text), total relation
(none/same system/conversion/bare), top-edge numeral, extra column, seal. Damage = feature unobserved (marginalised).
REAL = 1,119 tablets with >= 2 obverse entries (95% Susa); CLEAN = 289 undamaged. 1,008 distinct skeletons among 1,119
(934 seen once) -- no exact form repeats much (top skeleton: 10 tablets).
