pe52 cycle 1: EVERY SIGN HAS A WEIGHT, calibration of the instrument (5 Oct 2026)
Scripts tools/pe52_lib.py, pe52_run.py, pe52_sum.py, pe52_ur3.py; checkpoints data/pe52_ckpt/ (git-ignored).
Prior art: web search found no per-sign fixed-effect model of PE quantities; pe34 tested compound modifiers on
behaviour (not whole-entry strings vs log quantity); Monroe 2023 related signs to numeral systems, not effect sizes.
Engine: per tablet split (10 splits; A 50% of tablets fit, B 25% screen, C 25% reserved), 200 random log-linear
models (random sign subset 30-100%, min frequency 2-8, ridge 0.1-100, hard-threshold sparsity, 5-60 random pair
interactions, first/last-sign features, string length) = 2,000 models per corpus x mode. Survivors = top 10% on B
that beat a string-identity baseline (shrunk mean of the same string in training); refit on A+B, scored on C.
DESCRIPTOR rule (frozen here): sign present in >= 75% of splits' survivors, same sign of effect in >= 90% of
splits, |median effect| >= 0.15 log units, and removing it worsens prediction of NEVER-SEEN strings on C in
>= 75% of >= 3 splits (string identity cannot help there). IDENTIFIER: >= 10 tokens on >= 3 tablets, not a
descriptor, |effect| < 0.1 or sign-consistency < 0.75.
Modes: sys = log q minus system mean (sign effects include tablet-scale / genre); tab = log q minus the
leave-one-out mean of the same tablet and system (pure within-tablet shift).
