# PE-39 cycle 1: unsupervised machine translation PE <-> proto-cuneiform, numerals the only shared tokens (plain GRU, tools/pe39_common.py, pe39_run.py, pe39_profile.py)
| PE-<n>.<cycle> | method and control | result | verdict |
|---|---|---|---|
| PE-39.1a | Setup. Sentences = lines with >= 1 sign and >= 1 numeral: PE 6,531 lines (pe_corpus.json), proto-cuneiform 16,079 lines (pe2_pc_corpus.json, Uruk IV/III admin). Shared tokens = numeral code x count ('N14:2'); every sign is language-private. Model: shared embedding, shared bidirectional GRU encoder, attention GRU decoder with a target-language tag, output masked to the target script plus numerals; 2,000 steps (500 denoising only, then denoising + online greedy back-translation both ways). Held-out 15% of tablets per side. Lexicon: for each source sign, the target sign maximising P(t|s) - P(t) over the translated corpus. Held-out gain of a pair = rise in held-out round-trip NLL when t is banned from the decoder, minus the rise for 3 frequency-matched random bans. Web check: no PE <-> proto-cuneiform UNMT found (X-2 did embedding alignment, not generative back-translation) | built; 4 runs of ~35-40 min each on a shared, overloaded machine (load 25 on 4 cores) | method ready |
| PE-39.1b | KNOWN-ANSWER CONTROL: proto-cuneiform split by tablet; half 1 renamed ('pq|SIGN'), cut to PE size; half 2 the target. Truth = identity. Same model, seed 0 | identity recovered for 4/175 source signs with >= 15 occurrences, 2/85 with >= 40 (2.4%; chance ~0.7%). Translations are SHARP and WRONG: mean P(t|s) 0.69 (SZE -> N57 0.95, BA -> U4 0.96, NUN -> GAL, GI -> ME, SI -> BU, UD5 -> SZITA 0.99); only EN -> EN right. No-learning baseline (nearest numeral-profile, Hellinger) on the same split: 17/85 (20%), 3 seeds 15-17/83-85 | **FAILS the control.** Back-translation finds a confident private substitution code, a permutation mostly among frequency neighbours, not the true one; it does WORSE than simply matching numeral profiles (2% vs 20%) |
| PE-39.1c | Numbers-shuffled control on the known-answer pair (numeral groups permuted across lines of the renamed half) | identity 1/175 (>= 15), 1/85 (>= 40); profile baseline 2-4/83 | with shuffled numbers the profile baseline collapses (20% -> 3%), so numbers do carry the identity; the neural model is at the shuffled level with or without them |
| PE-39.1d | Held-out back-translation as a selection criterion (the prompt's 'improve held-out back-translation'), known-answer pair | mean pair gain +0.60 nats (24/30 pairs > +0.1) for pairs that are 29/30 wrong; the one correct pair (EN) +0.18; numbers-shuffled +0.55 | **Held-out round-trip gain does not mark correct translations.** Any consistent code earns it; the criterion is blind to truth |
| PE-39.1e | Real run PE <-> PC and the PE numbers-shuffled control (seed 0) | real: M288 -> N57, M218 -> SANGA, M388 -> UDU, M387 -> SAL, M297 -> BA, M346 -> DUG, M124/M009/M354 -> EN, M036 -> GAR; held-out round-trip NLL 1.00, numerals copied unchanged in 78% of lines (control pair 97%). Shuffled PE numbers: round-trip NLL 0.89 (better than real), same top translation for 34/154 signs, pair gain +0.57 (real +0.41) | real and number-shuffled PE are indistinguishable by every model score; given 1b, the real lexicon is uninterpretable (M388 -> UDU, M036 -> GAR look like readings but the control shows such pairs arise without truth). Nothing graded above C |
| PE-39.1f | Ur III <-> proto-cuneiform second known-answer pair (abs numeral bridge: system + quantile bin; gold of 37 Ur III words -> PC signs frozen before the runs in data/pe39_ckpt/gold_ur3_pc.json); neural run not reached (compute), profile baseline only | profile baseline 0/26-0/37 correct in 3 seeds (and 0 shuffled) | with only system + magnitude as the bridge, numbers carry no identity across two cuneiform corpora 1,000 years apart; this pair is dead before any learning |
| PE-39.1 | Cycle verdict | UNMT with numerals as the only bridge fails its known-answer control (2% vs profile baseline 20%), its stability/held-out criterion is blind to truth, and real PE is not distinguishable from number-shuffled PE | **KILLED in the plain form.** Next: force the numbers into the model (embeddings built from numeral profiles) so the network cannot invent a private code |
