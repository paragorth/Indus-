pe36 cycle 1 (4 Oct 2026): DO THE NAME SIGNS WRITE SOUNDS? la21 universals-only consonant x vowel grid (1 pure-vowel row + 14 consonant rows x 5 columns, cap 2; scored only by independent consonant/vowel tiers, consonant OCP, pure vowels word-initial, small cells) on the 65 commonest signs. No sign values from any script are inputs; true values only score the controls. Every corpus except PE names is subsampled by string type to the PE names' evidence (1,222 in-string bigrams among its top 65 signs). 100,000 moves per restart; stability = pairs sharing a row (row70) or column (col70) in >= 70% of 100-restart blocks; null = within-string shuffles (3-6 seeds x 100 restarts). Literature: Dahl proposes a small syllabic subset in PE names (LITERATURE.md; cdli.earth/articles/cdlj/2005-3); no blind phonotactic grid on PE was found, and no proposed values were used. Tools: tools/pe36_common.py, pe36_run.py, pe36_queue_c1.sh, pe36_report.py; checkpoints data/pe36_ckpt/ (report_c1.txt).
