# pe42 cycle 1: LEARN FROM THE SCRIBES' MISTAKES. Which single mental-arithmetic error families explain totals that do not add up?
# Script tools/pe42_cycle1.py (+ pe42_common.py, pe42_report.py c1). Checkpoint data/pe42_ckpt/c1.json, c1_report.txt.
# Cases: PE 93 tablets with written total(s) and readable numerals (pe30 cleaning, tiers 1-2); 60 fail under every base value set (dec/sex x fraction 1/2,1/6; capacity a-priori chain).
# Controls: proto-cuneiform (PC) 73 one-total tablets with S/B/SE numerals (25 fail); Mesopotamian count lists from the CDLI dump (MES; one szu-nigin2 line, 153 texts, mostly OB/Ur III/NB; 96 fail, many are category totals).
# Families (one error per tablet): OMIT (OMITH = entry repeats a neighbour's sign = eye-skip; OMITO other), DOUBLE, SYS (entry/total read in another value map), WHOLE (whole tablet closes in a non-base map), CONV (entry x 3,5,6,10,1/2,1/3,1/5,1/6,1/10), CARRY/XCARRY/NOCARRY (column-addition carries dropped/added/all dropped), DIGIT (+-1 of a code at a non-carry place), FOREIGN (discrepancy = an entry value from another tablet).
# Nulls (200 each): noise = another failing tablet's real discrepancy added to this tablet's entries; totals = totals reassigned within class and size bin; shuffle = entries re-dealt across failing tablets.
