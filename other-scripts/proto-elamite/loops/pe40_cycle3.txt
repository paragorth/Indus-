pe40 cycle 3: MASSIVE RANDOM ROTAS (tools/pe40_cycle3.py; data/pe40_ckpt/cycle3_all.json, cycle3.log).
Each player (724 tablets, 244 rare name signs) gets a random slot on a cycle of P = 4..24 slots; 100 random starts per fit half, each hill-climbed on the modularity matrix of the fit half (same slot weight 1, next slot 0.5), 3 random half splits, top 5 survivors scored on the held-out half. ROTA INDEX RI = held-out pair mass at cyclic distance 1 over distance >= 2, each relative to slot-size expectation; SAME = distance 0 over expectation. About 10,000 climbed random rotas in all (34 runs x 300).
First run discarded: the plain co-occurrence objective piles every player into one slot (SAME = P, RI 10^6); logged in data/pe40_ckpt/cycle3_collapsed.log. Rerun with the degree-corrected (modularity) objective. One split in 3 can still go degenerate (RI 300-500 on PLANT_ROTA_p8 / NULL0 at P 6), so read medians.
