PE4 cycle 1: are the entry middles item codes or names? MDL of a factorial (slot x value) code vs a free-string (name) code.
Tools: tools/pe4_build_controls.py (Ur III calibration corpora from the CDLI ATF dump -> data/pe4_controls.json), tools/pe4_common.py, tools/pe4_cycle1.py. Data: data/pe4_cycle1.json, data/pe4_cycle1.log.
Novelty check: LITERATURE.md, FINDINGS.md, STRATEGIES.md (pe2), pe3 (phonetic fingerprints, chunk MDL) and the Indus STRATEGIES.md contain no factorial / attribute-slot decomposition of PE middles; FINDINGS test e only compared uniqueness with a bigram model.
Setup: 110 distinct strings of >= 2 tokens per corpus, length profile matched to PE_all (mean length 2.8-3.4), 8 replicates. Strict factorial = k <= 5 ordered slots, one sign per value, at most one value per slot, independent presence; chunk factorial = slot values may be multi-sign runs. Name model = best of order-0 / order-1 Markov spelling. Gain = name bits - factorial bits per string (positive = item code).
PE classes: PE_all (all middles), PE_SDB / PE_C (entries with no class sign, counted / capacity numerals), PE_fin (middle before a final class sign), PE_M288 (before M288).
Positive controls: synth (planted 5-attribute herd code: sex x age x colour x breed x owner-group), herd_w / herd_s (Ur III Drehem livestock lines, attribute vocabulary filtered structurally: word on >= 20 tablets with >= 3 head animals; w = word tokens, s = sign tokens), tex_w / tex_s (Ur III textile lines, same filter).
Negative controls: drehemPN ('ki PN-ta' / 'giri3 PN' names from the same Drehem tablets), UrIIIseal (Ur III seal names), LinB (Linear B personnel names).
