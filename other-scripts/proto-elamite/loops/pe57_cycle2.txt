Rule (frozen 5 Oct, before any vessel data was examined): survive if a capacity mode lies in 0.5-1.0 l or 4-9 l; a mode near 2.8 l is further support; killed if no mode in either window. 'Near 2.8 l' was set to 2.33-3.36 l (x/1.2) after the Abu Salabikh table had been read, so the support test is not blind. Mode finders: KDE on log10 litres (Silverman bandwidth; peaks above 10% of the maximum), 2,000 bootstraps; BIC Gaussian mixture (1-4 components), 100 bootstraps.
