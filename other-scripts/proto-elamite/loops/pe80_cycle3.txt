pe80 cycle 3 (7 Oct 2026): HOW BIG IS A THING THAT IS COUNTED IN HUNDREDS? (candidate C6, added after C1 and C2 died)
Idea: ecology's abundance-size rule (Damuth): small things are counted in large numbers, big ones in small numbers. If ledgers obey it, a counted sign's typical count, with tablet effects removed, ranks the physical size (or unit value) of what it counts. This uses an outside physical scale (body and object mass) and never reads a sign's picture or a cognate. Prior-art check: no use of mass, body size or abundance scaling in any loop of the three scripts (grep 'Damuth', 'body mass', 'allometr', 'abundance': 0 hits); web search found none. Closest earlier work: pe52 (sign weights within tablets) and pe61 (adjacent-number size separates commodity from count) used magnitude, but never as a size ruler against outside masses.
Tools: tools/pe80_c3.py (Ur III calibration), tools/pe80_c3_pe.py (PE). Frozen BEFORE any Ur III count was looked at: data/pe80_mass_table_frozen.json (34 Ur III nouns, rough kg per unit), sha256 089fe04e3ef5246715e4e84689be6fe2894f089a71baca5e7dd9c073100109c5. Scale estimators: E1 median log10 count per word; E2 word fixed effect with tablet fixed effects (alternating means, 25 iterations), blind to word identity.
