pe9 cycle 2 -- approximate Bayesian computation over bag models (tools/pe9_cycle2.py, pe9_cycle2_abc.py;
reference tables data/pe9_ckpt/c2_*.npz; results data/pe9_cycle2.json, pe9_cycle2*.log).
Reference tables: 1,000,000 simulated corpora on the PE fit-set structure (206 tablets; same strings per
tablet, same string lengths, same tablet order), 100,000 each on the Ur III and Linear B structures.
Prior: model uniform over LM / POLYA / BAG_WR / BAG_WOR / STAMP; base unigram or bigram tempered by
gamma ~ U(0.7, 1.3); bag size K ~ log-U(2, 300) sign types; copies c in {1,2,3,5,10}; eps ~ U(0,1) share of
signs drawn from outside the bag; POLYA theta ~ log-U(0.1, 300); session S in {1,2,4,8} consecutive tablets
sharing one bag. 11 summary statistics: within-tablet rare-sign sharing between strings, cross-tablet
sharing and their log ratio, re-use rate, P(>= 3 strings | >= 2) per (tablet, sign), within-string
repetition, types/token, hapax share, top-10 share, adjacent-tablet vs random-tablet sharing, rare re-use.
Rejection ABC, MAD-scaled distance, nearest 0.1% accepted. String lengths are conditioned on, not modelled.
