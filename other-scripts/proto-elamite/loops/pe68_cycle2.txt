pe68 cycle 2: thousands of random completion models predict what each fragment lost; frozen, then checked against the joined text
(tools/pe68_lib.py, tools/pe68_c2.py predict|score, tools/pe68_c2b.py; frozen file data/pe68_frozen_join_predictions.json, sha256 fca3466e3cea930b...; scores data/pe68_ckpt/c2_scores.json)

Design. Every model is trained without the 14 joined tablets (hash split of the rest: train half / held-out half). A model predicts, from the visible fragment only, for the lost part: (a) number system of each lost numeric line (capacity sub-units or not), (b) the final (class) sign of each lost entry, (c) the size of each lost number (log10 value, 0.1-dex bins), (d) the header if lost; scored in bits (lower = better). 3,000 random models per corpus: random mixture of fragment cache / reading role sets / corpus frequencies, random smoothing, size shrinkage and spread, and random on/off flags for the pe59 reading's parts (SYS = one number system per tablet, calibrated on training cuts; ROLE = pe59 MEASURED / COUNTED / ALLOT / PERSON / FRACLINE sign classes; HDR = header by tablet kind). READ = best all-flags-on model and CACHE = best all-flags-off model, both chosen on training pseudo-cuts only. Nulls: CORPUS (frequencies only), RANDTAB (the fragment replaced by a random training tablet of the same size, 10-30 draws), SHUF (READ with 49 frequency-matched shuffled role sets). Predictions on the 29 real fragment views were written and hashed before any hidden line was read (the scoring script refuses a changed file). Controls: geometry-matched pseudo-fragments (visible share drawn from the real fragment shares) of held-out PE, proto-cuneiform (correct readings, pe59 PC_KNOWN) and Ur III (correct readings: grain, beer, oil ... vs sheep, cattle ... vs workers) tablets.
