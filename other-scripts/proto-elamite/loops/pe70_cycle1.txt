pe70 cycle 1: a seal means someone signed for it -- what separates sealed from unsealed tablets?
(tools/pe70_common.py, pe70_feats.py, pe70_c1.py, pe70_c1b.py; data/pe70_ckpt/c1.json, c1b.json; controls c1_ctrl.json. A first control run mapped CDLI catalogue rows by the wrong id column (id instead of id_text) and was discarded; all control rows below are from the corrected run)
Data: 1,581 PE tablets, 192 sealed (ATF seal notes, CDLI catalogue seal_id / seal note, pe33/pe35 seal ids), 361 features
(base signs df >= 5, header sign, number systems, dominant entry-final sign, lines, entry length, single-sign share,
columns, reverse, numeral share, damage, header present, catalogue height x width, thickness, h/w, fragment flag).
Seal data used as presence/identity only; no picture and no reading of any sign.
