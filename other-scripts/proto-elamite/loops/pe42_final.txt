# Idea: model every PE total that does not add up as a single mental-arithmetic error (omission, eye-skip, doubling, wrong number system for an entry/total/whole tablet/one code, commodity conversion factor, dropped/extra/all carries, one-unit digit slip, entry from another tablet, chunked omissions, prefix/suffix totals). Score which error processes explain the real discrepancies better than three nulls (noise = another tablet's discrepancy; totals reassigned; entries re-dealt). Then thousands of sign-specific error hypotheses with a family-wise max null and split-half re-test.
