pe55 cycle 3: does a sign's activity replicate between disjoint halves? (5 Oct 2026)
Script tools/pe55_cycle3.py (and pe55_cycle2.py rulers pe); checkpoints data/pe55_ckpt/c3_*.json.
20 random half splits; the physics fit (persons and stock, no area) is run separately on each half;
per sign, class (person / small stock / large stock) and period (day / month / year) are compared between
halves. Null: the same on data with capacity values shuffled across lines (10 x 20 splits). Control: Ur III
opaque, thinned to PE size (220 tablets, 13 keys), with the truth class of each noun.
