# PE-38 cycle 1: type inference for every sign at once, pre-registered accounting rules + line type-checker
# tools/pe38_core.c (tempered Gibbs, incremental per-line role counts), pe38_common.py, pe38_c1.py, pe38_report.py (c1g);
# checkpoints data/pe38_ckpt/c1_*.json, c1.json (git-ignored).
# Roles: NAM name, PRO profession/class, COM commodity, ANI animal, MEA container/measure, HDR header/office, VRB transaction
# verb, TOT total marker, QUA qualifier. Unit = base sign (variants merged, compounds whole), >= 2 tokens (403 PE types).
# Energy = Dirichlet-multinomial over 8 occurrence features (slot, line kind, number system, size, line position, next and
# previous line, doc spread) + 2*sqrt(n) nats per broken type rule (e.g. TOT: >= 50% of tokens on total lines, >= 3 tablets;
# VRB: mostly off entry lines, not alone; ANI/PRO: counted heads, ANI large counts, PRO small) + 2 nats per line that fails
# the type-checker (entry: a countable head, no HDR/TOT; total: a TOT sign or the head role of the entry it closes; header:
# HDR, NAM or VRB; no TOT off total lines). Total lines = arithmetic closures of the running sum (330 PE lines) or the single
# numbered reverse line (pe21). 500k updates per chain, T 8 -> 1; PE 16 chains, others 8.
# Chains do not mix: each freezes in its own mode (PE end-state violations 329-663). "Forced" = same role in >= 90% of
# the best-scoring third of chains (good solutions); pooled cross-chain forcing gives only 1 PE sign.
