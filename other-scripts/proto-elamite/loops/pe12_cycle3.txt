Verdict cycle 3: no tablet-level verification mark, no check digit on totals, and the arithmetic mismatches are not the
single-sign slips that a check digit is designed to catch. The one positive result is structural: some PE lists are
built from fixed multi-line records whose companion line (e.g. M376 with 1/4 unit) repeats after every main line.
Next stranger idea: treat each two-line record as one unit and ask whether the COMPANION line's sign or number
(M376 1(N08A) vs M367~i 1(N01)) is computed from the main line (its number or class sign). This is a record-level check
digit, and a cross-tablet test on all lists with a lag-2 excess would show it.
