# Prior art: web search (naming-grammar / genealogy simulation for undeciphered-script names) found nothing; pe7 tested tree-likeness (phylogenetics), not a generative naming grammar; pe40 tested a rota. Not in LITERATURE.md.
# Data: PE = 1,707 name-like strings on 696 Susa tablets (pe40 definition). UR3 control = 1,707 Ur III Umma/Girsu personal names from fixed name contexts, divine determinative deleted, cut into opaque syllable signs, tablets sampled to the exact PE tablet-size template; truth kept aside: 36 god signs, 80 'A dumu B' (son of) tablets.
