PE-62 cycle 1: READ WHAT THE CLERK LEFT OUT (masked-class inference by random classifier search)
Date 6 Oct 2026. Scripts: tools/pe62_common.py (corpora, features, random search), tools/pe62_c1.py (one run),
tools/pe62_sum1.py (table), tools/pe62_sched.sh / pe62_runq.sh (2-worker queue). Checkpoints data/pe62_ckpt/c1_*.json
(git-ignored).

Novelty check: LITERATURE.md, FINDINGS.md, STRATEGIES.md and a web search. Born et al. 2023 (CAWL) bootstrap a classifier
to choose the reading of a numeral notation. Nobody has inverted the problem for the class of an entry: train on entries
whose class sign is written, delete it, then read back the class of entries and tablets that never wrote one. la54 ran this
for Linear A commodities; this is the first PE run. pe56 (forgers) and pe61 are running separately and are not repeated here.

Set-up. 1,585 PE tablets, 8,234 entry lines. Labelled = final sign in a pe59 class set (MEASURED 714, COUNTED 942, PERSON 941,
ALLOT = M288 732, FRACLINE = M376 160; 3,489 entries). Every class sign is deleted from every name string before features
are built. Unmarked = 2,459 name-only, 1,894 bare-number and 392 with a class sign only inside the string (4,745 in all).
Features (10 groups): numeral system and size; rounding and digit shape; name-string signs; first and last remaining sign;
position; classes of the visible neighbouring entries; tablet size (entries, height, width); tablet number system;
header sign and role; museum batch (CDLI primary publication, museum prefix, site).
Search: random hypotheses = random group subset x random group weights x family (logistic, naive Bayes, extra trees) x
random hyper-parameters, scored by tablet-grouped 3-fold CV on 70% of tablets (hash split); top 15 ensembled and judged once on
the held-out 30% of tablets with the class masked. 1,000 hypotheses for PE with numbers, 600 number-blind, 300 for each
control; 60-120 per null or plant run (about 4,000 hypotheses and ~12,000 fits in all). The 'first 150' ensemble is reported
to match the null budget.
Controls: proto-cuneiform (GRAIN, PRODUCT, ANIMAL, PERSON, GOODS signs deleted) and Ur III (sheep and goats, cattle,
person, grain, oil, textile and metal words deleted; units turned into a system feature), each cut to 3,489 labelled entries.

| PE-62.1a | PE, numbers allowed. Nulls: training labels shuffled across tablets (x3), shuffled within each tablet (x3), numerals shuffled across entries with the tablet system shuffled across tablets (x3). | Held out (1,112 entries): acc 0.672, balanced 0.667, 0.950 bits/entry (first-150 ensemble 0.941); majority 0.246. Label shuffle max 0.254 / 0.001 bits. Within-tablet shuffle 0.603-0.633 / 0.766-0.792 bits. Number shuffle 0.600-0.605 / 0.707-0.730 bits. Copy the tablet's commonest written class: acc 0.585. Every top-15 hypothesis uses the neighbour group. | B: the masked class is readable (+0.95 bits), but ~0.8 bits of it is the tablet's own habit. What is left inside the entry (~0.15-0.18 bits over the within-tablet shuffle) is about the same as what the numerals add (~0.22 bits over the number shuffle). |
| PE-62.1b | PE, number-blind (numeral, rounding and tablet-system groups barred). | acc 0.601, balanced 0.539, 0.743 bits (first-150 0.738); this is the within-tablet shuffle level (0.77-0.79 bits with numbers) and only 1.6 points above copying the tablet. | B (negative): once the numbers are hidden, the name string, position, header and batch add almost nothing beyond the tablet's other entries. |

B: 10% of labelled entries get class PLANT and x5 numerals. | PE A: M097 (30 tokens, 8 held out) recall 0.00, but mean P(PLANT) 0.19 on true vs 0.009 on others; M259 (46) recall 0.94, precision 1.00; M347 (48) recall 0.47, precision 1.00. So at PE size the search can find a hidden class carried by one name sign, if the sign recurs about 45+ times. |

Verdict cycle 1 (B): Proto-Elamite masked classes come back at 0.95 bits/entry, but the information sits in the tablet (what the
other entries say) and in the numerals. Name strings carry little entry-level class information: the number-blind model
is at the within-tablet shuffle level. The controls pass, and Ur III shows what a corpus with class-bearing words looks like
(number-blind +0.17 bits over its within-tablet shuffle; PE -0.03 to -0.05). PE behaves like proto-cuneiform, not like Ur III.
