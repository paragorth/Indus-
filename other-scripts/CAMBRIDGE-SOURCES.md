# Cambridge sources for open data gaps (4 Oct 2026)

Checked with the iDiscover Primo API, the Apollo DSpace API, Cambridge Digital Library (CUDL) item JSON and transcription services, Cambridge Core and Fitzwilliam data pages. "Login" means a Cambridge reader card or Raven account is needed. Links to iDiscover records: `https://idiscover.lib.cam.ac.uk/discovery/fulldisplay?docid=alma<MMS>&vid=44CAM_INST:44CAM_PROD`.

Short answer: Cambridge has no open item that fills a data gap directly. Every gap is held in print (UL, Classics Faculty "CLA" and its Mycenaean Epigraphy Room, Haddon "ETH"), so a Cambridge reader could close most of them in one library visit. The only openly fetched item is a control text: the Equatorie of the Planetis transcription, which contains cipher passages.
