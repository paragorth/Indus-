# Candidates (all: thousands of random hypotheses scored on train folios, survivors re-tested on held-out folios; planted control = a real
#  text written through the v72 verbose code + surface; kill = line/paragraph shuffles and Voynich-fitted generators):
#  I1 THE PAGE TRANSLATES ITSELF. Each page holds its content twice: a text and its translation or gloss, interleaved by line, by paragraph,
#     by half-paragraph, by half-page, or inside each line (first part / second part). A word-translation model (IBM-1) learned on train
#     folios should predict a unit from its partner far better than from a same-distance non-partner (phase/offset twin); monolingual text,
#     generators and shuffles give no phase asymmetry. Meaning payoff: a lexicon between the two layers (equivalence classes of words).
#     Planted: Psalms Hebrew/English verse-by-verse (line interleave and in-line halves), Celsus Latin/English paragraph pairs.
#  I2 THE MEANING IS IN WHAT EXCLUDES WHAT. Paradigmatic alternatives (hot/cold, root/leaf, a plant's one colour) never share an entry: a
#     sparse network of page-level MUTUAL EXCLUSIONS between recurring words, beyond spelling habit, is a semantic signature (sets of
#     alternatives = attribute values). Random word-set hypotheses scored for exclusion; generators make attraction, not exclusion.
#  I3 IT IS A DIALOGUE. Master-pupil dialogue (common in medieval teaching texts) alternates two speakers with swapped person-deixis.
#     Random turn segmentations (paragraph, line, run) scored for an alternating two-idiolect mixture with swapped word pairs; planted
#     dialogue text; kills: N4 says line modes do not alternate (so line-level turns are already unlikely; paragraph turns untested).
#  I4 THE BOOK QUOTES ITSELF. A capitula list, rubric or summary repeats later headwords in order: search all stretches for order-preserving
#     subsequences of later paragraphs' distinctive words (not sorted glyph order, which v19 did). Planted capitula list.
#  I5 COINAGE TREE. A writer inventing code words derives a new word from the code word of a related concept: each type's first occurrence
#     has a nearest earlier type; parent-child pairs should share contexts more than spelling-matched random earlier types.
#  I6 THE TEXT IS A RECORD OF ACTIONS ON OBJECTS (state-change log): recipes bind a verb to the objects it changes; objects stop recurring
#     once consumed. Random verb-class hypotheses scored for 'consumption' (object stops after a verb class). Close to v76/v92-K6; ranked last.
