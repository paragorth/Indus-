# v27 cycle 1: THE LINES WERE CARDS. Within-paragraph card sequencing (4 Oct 2026)
# tools/v27_seq.c (exact Held-Karp up to 14 body lines, SA beyond), tools/v27_lib.py, tools/v27_cycle1.py
# Head line fixed as start; body lines are cards; the solver never sees the written order.
# Scorers fitted on each corpus version: J = log P(first word of j | last word of i) / P(first word of j), trained
# ONLY on within-line word pairs (backoff: last glyph, unigram); L = idf-weighted shared words + near-identical
# words (edit 1, len>=4); S = J + L. Paragraphs >= 3 lines: LA 434, IT 401, ZL 663, IT2a 638.
# Statistics: W = z of written order vs 200 random orders; G = z of the best order; PE = (best - random mean) /
# (row-max upper bound - random mean): path-likeness, ~1 when each card has one clear successor; mb = mutual-best
# rate; adj = written adjacencies found in the best path (chance 1/(n-1) per edge). Nulls 2 seeds each; values
# are means. G and PE are blind to the written order, so they are the hidden-order test.
