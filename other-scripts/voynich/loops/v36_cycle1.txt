# v36 cycle 1: do the v30 A->B rewrite rules target stroke-defined glyph classes? (existing g3 rule sets, 2 seeds x top-10/top-30)
Method: each v30 rule applied alone to the source words; changed words cut into glyph units and aligned (difflib). Per rule: targeted glyphs (deleted/replaced), context glyphs (left/right of the change), 1:1 substitutions. COH = mass-weighted mean pairwise feature similarity of targeted glyphs; CTX = same for contexts; SUB = feature similarity of a and b in 1:1 substitutions. Null = 2,000 frequency-stratified (4 strata) permutations of glyph labels on the similarity matrix (random glyph classes of the same size, mass and frequency). Features: Voynich = v25 hand strokes (vhand) and v25 EVA-font image similarity (vimg); Latin-script pairs = phonetic value of each letter (binary features, combining marks marked). z = mean over 2 seeds x (k10, k30).
