# Representation: each word (glyph units) -> 7 lossless anchored fields f1 l1 f2 l2 f3 l3 mid (three anchor schemes: alternate ends, start-heavy, end-heavy). A decomposition = random partition of the 7 fields into 2-4 wheels; wheel value = tuple of its fields. Compactness = held-out bits/token of the independent-wheel product model (train folios, odd lines -> even lines; unseen values spelled field by field). Pages split by md5 into train (decomposition search) and test (meaning test) halves.
# Meaning statistics on test folios (odd lines -> even lines): g_page = bits gained by a Dirichlet own-page model over the stratum model (section x hand x language x line role x word position; alpha tuned on train folios); g_self = g_page beyond the two nearest same-stratum pages; g_para = same-paragraph minus other-paragraph-of-the-page; LIFT = rare wheel values (corpus count 2-20): present in the odd lines of the own page vs the other pages of the same section x hand x language (one event per distinct page x value; the token-level version gave Markov 11/60 calls and was replaced). Content call = wheel lift z >= 3, lift minus complement lift >= 0.5, complement z < 2.
# Plants (all on Voynich words shuffled within hand+section, so carriers have no page signal; f1 given a smooth AR(1) page drift in every plant): C_HERB = Konrad von Megenberg's plants (Buch der Natur), one entry per page, each content word (top 60 types excluded) -> a Lullian concept pair written at f2 and l2 from an 18-letter alphabet; C_HERB9 the same with Llull's 9 letters; C_HERB30 30% of tokens; C_ASTR = Hyginus, De astronomia, one entry per paragraph; HABIT / HABIT_S = f2, l2 drawn from page distributions drifting smoothly (strength 0.35 / 1.0), no content. Kills: SHUF0/1 = word positions shuffled within hand+section; MARK = glyph Markov-2 per section x hand.
