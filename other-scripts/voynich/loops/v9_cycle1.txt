# v9 cycle 1: "the text was dialled out of a volvelle" -- independent-ring volvelle, rule R1

Script: tools/v9_cycle1.py (+ v9_lib.py, v9_report.py). Checkpoints: data/results/v9/c1m_*.pkl, c1_all.pkl.
Set-up. Each corpus gets its own 3-slot grammar (v7 slot model: corpus-learned glyph order cut into prefix / core / suffix
bins); each ring carries the 12 commonest fillers of its slot + OTHER (13 symbols). Volvelle = ring of n cells (n = 40 or 48,
picked on train), one filler per cell (duplicates allowed), the ring turns by a step drawn from a learned kernel q(d) between
words, and is set from a learned start distribution at every line start (reset) or carried across line breaks (no-reset).
Search: population Baum-Welch on the circulant HMM with free per-cell emissions (6 random starts x 40 iterations, best 2 x 120
more) = the "soft" volvelle; then hardened (one filler per cell, every filler on the ring) and refitted = the true volvelle.
Train = alternate pages, test = the other pages (17.3k test tokens per corpus; planted uses the Voynich line lengths).
Bits/token below are held-out; "gain" = bits saved against M0 (start distribution + iid fillers). Parameter budgets per ring:
hard volvelle ~ n labels + n steps + n start probs (~120-145), within-ring Markov-1 ~175-182 non-zero counts: comparable.
Prior art (quick web search 4 Oct 2026): Rugg 2004 (table + Cardan grille, prefix/root/suffix columns; generator, never fitted);
'Syntaxis Volvella' Zenodo preprints 2026 (tri-rotor 17:13 disc claimed, no likelihood test against a Markov model or planted
recovery seen); voynich.ninja threads 5366/5600. No published likelihood fit of a volvelle with a planted-recovery control found.

Cycle verdict: a 3-ring volvelle with a simple turning rule does NOT explain Voynich word sequences. The method is calibrated
(planted volvelle recovered to within 0.01-0.09 b/tok of the oracle and its rule exactly), so the failure is informative:
there is almost no within-ring sequence to explain (M1 gains 0.02-0.04 b/tok), the fitted rule is "turn anywhere", and the
independence of rings inside a word is strongly violated.
