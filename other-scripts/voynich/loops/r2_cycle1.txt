# R2 cycle 1 -- random PROGRAMS (not random hypotheses): calibration on planted generators and natural-language controls
# Tools: voynich/tools/r2_data.py (corpora, KN baseline, terminals), r2_search.c (C engine: random postfix programs + evolution),
#        r2_run.py (2 workers, checkpointed), r2_report.py (held-out test, bootstrap, dissection). Results: voynich/data/results/r2/.
# Language: postfix stack programs (<= 15 instructions) over 18 terminals (previous symbols P1-P8; AB = symbol above in the previous
#   line; AW/AW2 = same slot in the previous / second previous word; FW/FL = first symbol of word / line; counters PW, PL, WI, LI,
#   CW, LPW, LLW), ops add sub mul mod min max eq lt if, learned lookup tables TAB1/TAB2 (table-and-copy machine; entries = majority
#   next symbol on training split A), and LSYS (4-rule L-system template indexed by its argument). Output = predicted symbol or abstain.
# Score: total description length on held-out documents. Each symbol coded by p = lam*[sym == program output] + (1-lam)*p_KN, one lam per
#   table-purity bin (4), fitted on split B; GAIN = KN bits - (program bits + table bits + lam bits + residual bits). The KN baseline
#   (interpolated Kneser-Ney, order chosen on B: Voynich 3, LA 2, PE 1, Latin 5, Linear B 3) is trained on A. Search: random programs
#   then evolution (mu+lambda, tournament, subtree mutation and crossover, restarts), fitness = net gain on B; the 30-program hall of fame
#   is then tested ONCE on split C (documents never seen), doc-bootstrap p, Bonferroni x30.
# Web/literature check (4 Oct 2026): MDL-fitness genetic programming exists in general (Iba, Zhang 1995); Voynich MDL work is morph
#   segmentation; Rugg/Timm/Zandbergen fitted ONE hand-designed generator each. No blind search over generator programs found: kept.

Gain is at line start (+395) and on the deterministic '#' (+198); top symbols predicted = the 3 planted commodities PU, SU, TA | PASS: the planted cycle is recovered blind (all 3 commodities, at the right slot) |
