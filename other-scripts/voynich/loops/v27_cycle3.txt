# v27 cycle 3: TWO WITNESSES + MASSIVE RANDOM GUESSING (tools/v27_cycle3.py, tools/v27_report3.py)
# If body lines are shuffled cards of a once-continuous text, two independent witnesses must point to the same
# hidden successors without the written order. Witness A = a junction hypothesis (feature of the LAST word of line i
# -> feature of the FIRST word of line j; table trained only on within-line word pairs); witness B = idf-weighted
# shared words of line INTERIORS (first and last words excluded). Per paragraph (3-12 lines, B non-empty; head
# fixed; exact DP; random tie-breaking) the best A-path and B-path are compared: shared undirected edges minus the
# random-path expectation -> z summed over paragraphs. 2,000 random hypotheses (end feature x start feature from
# {last 1/2/3 glyphs, first 1/2 glyphs, length, first+last, whole word} x random glyph-class merges into 2-10 classes)
# per corpus version, 11 versions (~22,000 hypothesis runs, ~5 CPU-h). Analysis uses the ~860 hypotheses whose
# A-features touch only the line-final and line-initial words (disjoint from B).
