v67 EACH LINE SAYS ONE THING, cycle 1 (5 Oct 2026): calibration of line-consensus token streams
Scripts: tools/v67_lib.py (corpora, plants, generators, consensus rules, scoring), tools/v67_c1.py, tools/v67_rep1.py. Checkpoints: data/v67_ckpt/ (git-ignored).
Prior-art check: FINDINGS/STRATEGIES have line-level work (v9 line make-up, v20 conserved balance, v22/v27 no line order, v61 sealed line ends, v62 line likeness) but no test that reads one consensus token per line and scores the line-token stream as a text. A web search (5 Oct 2026) finds Levenshtein-burst and word-family studies on voynich.ninja (similar words close together), not a line-as-one-word reading.
Idea: if each line is one word of the real text written as redundant variants, a consensus token per line gives back the real text (one token per line, ~4,100 tokens), which should then have word-order structure.
Scoring of a line-token stream (within-page line shuffle null, 20 shuffles): MI = bigram MI of consecutive DIFFERENT tokens; ASYM = directional asymmetry n(a->b) vs n(b->a) (similarity drift is symmetric, word order is not); REC = ordered token pairs recurring on >= 2 pages; LANG = sum of the three z. Plus REP (adjacent identical tokens / shuffle), Zipf, types.
Consensus rules: glyph reduction (identity / random 3-12 class map / delete 1-6 glyphs as padding) x unit (prefix 1-4, suffix 1-4, whole, infix, bag of glyph 2-3-grams) x aggregation (mode, idf-weighted, medial words only, top-2 pair) x tie rule. 6 hand rules + 150 random rules.
Corpora (all in the ZL3b line/page skeleton, 4,130 P lines, 207 folios): ZL3b, IT2a; nulls ZLshufw (words shuffled across the lines of each page), LRG (line-reuse generator: each line draws its words from the page pool weighted exp(-0.3*lev) to a seed word; beta tuned to the Voynich line likeness), LRGd (same, seed taken from the previous line with p 0.3), CPV (copy-and-vary); plants: Caesar (Lat) and Manzoni (Ita), one real word per line, opaque glyph code, each line = Voynich-length list of variants (truncate + random Voynich ending/head + glyph insertion) with filler share 0.25 (S), 0.6 (M), 0.85 (V = matched to the Voynich line likeness), and 'hard' (random chunk of the code, filler 0.35).
