v67 EACH LINE SAYS ONE THING: final (6 Oct 2026). Cycles: loops/v67_cycle1.txt, v67_cycle2.txt, v67_cycle3.txt.
Idea (arrow in the dark): every line is one word of the real text written out as redundant variants; one consensus token per line gives back a much shorter real text, which should read as language.
Done: 1,156 fixed consensus rules (glyph reduction x unit x aggregation; 156 in cycle 1, 1,000 in cycle 2 on 9 corpora with page-word-shuffled twins, odd/even folio held-out) and 120 learned line compressors (latent class per line; 15 settings x 8 corpora, each with its twin). Stream scores: off-diagonal MI, directional asymmetry, ordered pairs recurring across pages, adjacent repeats, recurring trigrams, lag profile, section NMI, all against within-page line shuffles.
Controls: Caesar and Manzoni laid one word per line into the ZL3b line/page skeleton through an opaque glyph code with Voynich-like variants (filler 0.25 / 0.6 / 0.85); a line-reuse generator tuned to the Voynich line likeness (with and without drift); copy-and-vary.
