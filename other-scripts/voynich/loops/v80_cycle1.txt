v80 THE PAGES ARE TABLES WRITTEN AS LINES, cycle 1: MASSIVE RANDOM TABLE-HYPOTHESIS SEARCH (6 Oct 2026). Scripts: tools/v80_lib.py, v80_c1.py, v80_report.py. Checkpoints: data/v80_ckpt/c1, c1b (git-ignored). Two CPU workers. la68 (Linear A) running elsewhere, not touched.
Idea (arrow in the dark): if Voynich tokens are values (v78 C, v75 C-), a page may be a table written out row by row: line = row, word index or x-position = column, values of one column drawn from a column-specific stock or stepping down the column.
Prior art (web, 6 Oct 2026): positional word studies (line-start/line-end preferences, 10 vertical stripes per page) and table speculation on voynich.ninja; Stolfi's notes on line structure. No calibrated search of column hypotheses against real tables was found. In this repo: v6 (reading orders, word-under-word MI) and v7 (planted numeric tables) are related; this cycle scores COLUMN VALUE SETS (global and per page) and vertical stepping, not reading order or digits.
Statistic: nested held-out ladder, EM mixture weights fitted on one leaf half, bits/token on the other: A0 = global unigram + edge law (first/second/last/interior word) + page vocabulary + line vocabulary (line mode); + global column law of the hypothesis (g_glob); + page-local column law (g_loc); + token above in the same column (g_vert, a learned stepping rule). Tokens after the frozen v72 E1c extraction. 1,500 random hypotheses per corpus: alignment L (word index), R (from line end), M (index mod C), X / XR (glyph-count x-position bins, width 3-14, offset), P2 (row spans two lines); C = 2-14; table unit page / paragraph / 8-line block / half page; token = full, first two symbols, last symbol. Search-corrected: the 10 best hypotheses on the discovery half, best of them on the held-out half ('best10'). Kill null for every corpus: the same search on the corpus with INTERIOR words shuffled inside each line (first and last word kept; line mode, page vocabulary and edge effects kept, columns destroyed). Column structure = real minus interior-shuffle.
Controls through the v72 surface (merge code + planted surface), one table row per line: T_KAL Julian kalendar (golden number when present, dominical letter, Roman date, 2-3 words of real kalendar verses OCR'd from Hampson, Medii aevi kalendarium 1841, archive.org mediiaevikalend01hampgoog); T_ALF Alfonsine mean motions (sun, moon, anomaly in signs/deg/min/sec, Alfonsine daily rates; days, months, years, 20-year steps; 13 cells); T_HOR planetary hours (hour, day/night, 7 weekday rulers in Chaldean order) + unequal-hour lengths for 7 climes; T_CON concordance of Isidore (headword + 1-4 book/chapter refs); T_DOS dosage table on Antidotarium/Apicius ingredients (2 ingredients, unit, Roman quantity; quantities drawn at random, semi-planted). '...d' = the same table copied with 15% of cells dropped (blank cells vanish). Prose: Isidore, Brumati, German. Generators fitted to ZL3b: SELFCIT, SC10, MK2, JUNC, STACK, WSHUF. The computed tables reproduce the content of such tables; no transcribed Alfonsine table was usable (incunable OCR).
