Grades:
- A (method): through the same merge code, planted surface and E1c, a held-out real designation system is put back in its kind at 0.34-0.54 (permuted-label null mean 0.06-0.09, max 0.20-0.32). But a raw fingerprint carries a kind in statistics that a generator fitted to the system copies (held-out reference generators classed as generator only 0.28-0.34). Subtracting each system's own generators fixes this (0.87) (V-75.1.1-2, 2.2).
- A (measurement): at the glyph level the E1c stream is outside every real system spelled through the same machinery (word length 3.9 vs 5.3-7.8 symbols, h2 1.9 vs 2.9-3.2, slot rigidity 0.86 vs 0.60-0.65; nearest-chunk distance 14-15 vs reference q99 10.6). Any kind label from those features is extrapolation (V-75.1.4).
- A (limit): glossary, book index and library catalogue form one confusable family under this fingerprint (V-75.3.6).
- B (negative): no calibrated test assigns the Voynich to ingredient lists, apothecary drawer or jar labels, star designations, nomenclators, monastic sign lists, alchemical symbol lists or modern codes (V-75.1.3, 2.3-2.4, 3.5).
- B (measurement): token doubling. The same payload token written twice in a row: 0.029 per adjacent pair (z +11.6 against all real systems, 0.000-0.004 in every kind; Voynich generators 0.014). Every real system doubles less than its own generators; the Voynich doubles more. ABC doubling rate 0.04-0.05 vs 0.012-0.020 in its generators (recovered at r 0.88 in calibration) (V-75.1.5, 2.1, 3.4).
- B: a plain designation grammar (records of a few fields, ~2,600 designations, ~40% section-specific, page re-use ~5%) predicts the Voynich's held-out type features once the first word of each line is set aside (error 0.67 / 0.96 vs calibration q90 0.94). The earlier miss was the line machinery E1c leaves in place (V-75.3.2-3).
- C (guess, reworded from v72): the payload is a short-entry reference list, glossary/index-like, rather than running language or any other designation kind tested. How sure: weak. The Voynich lands in this family 0.24-0.65 of votes against 0.00-0.42 for each of its generators in every calibrated cell (both transcriptions, both replicates), but the plurality open-set vote is 'generator' and copy-and-vary text reaches the same family when forced to choose. What it predicts about content: a list of short designations (a headword plus a few qualifier tokens) with a different stock per section, almost no re-use of a designation within a page, and some designations written twice in a row (a doubling mark, e.g. 'the same again', a plural or a count). Would support: (1) the doubled pairs sitting at the start or end of records (paragraph or line edges after the line-initial word) more than mid-record; (2) the same doubled token recurring on pages of one section only; (3) any further transcription (P2-type) giving the same doubling rate. Would kill: doubling explained by E1c merging (rate falling to the generator level under a finer extraction such as E1 with d kept and k/t, ch/sh kept apart), or the list-family lean disappearing in an independent transcription.
