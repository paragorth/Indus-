# v19 cycle 1 - 'SOMEWHERE THE TEXT IS SORTED' (tools/v19_sortsearch.c, v19_lib.py, v19_cycle1.py, v19_report1.py; data/results/v19/c1/, c1_report.txt)
# Idea: if any stretch is a glossary/index/name list, its entries were written in the writer's own glyph order. For every stretch, search the
# glyph order (permutation of ~20-30 glyph units, end-of-word included) that makes the entries most sorted: tau = (concordant - discordant)/decided
# pairs between position and sort key. Keys: F first glyph, L2 first two, L full lexicographic, R1 last glyph, R reverse dictionary.
# Search = linear-ordering problem: 2,000 random orders per stretch (200,000 in pooled mode), then iterated local search (insertion moves,
# 5-6 restarts x 15-25 kicks). Null: entries shuffled within the stretch and the SAME search re-run (60-100x) -> z, p.
# Stretch kinds: pagewords (all words of a page), win5 (5-line windows), lineinit (line-initial words of a page, paragraph-first lines excluded),
# linefinal, parainit (20 consecutive paragraph-initial words in a section), labels (per folio, ZL). Pooled = ONE order for all stretches of a cell.
# Corpora: Voynich ZL3b, IT2a (P lines, '?' words dropped); positive: Isidore Etym. X (alphabetical headwords, la.wikisource / Migne PL 82;
# data/derived/v19_isidore.json), 8 planted Voynich pages (4 types, each under its own random order); negative: Isidore XVI and XVII (prose).
# Latin is letters a-z (j->i, v->u); the engine sees only symbol ids, i.e. any letter substitution.
