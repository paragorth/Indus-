v67 EACH LINE SAYS ONE THING, cycle 3 (6 Oct 2026): a learned line compressor
Scripts: tools/v67_mix.py (mixture of multinomials, one latent class per line), tools/v67_c3.py, tools/v67_rep3.py. Checkpoint: data/v67_ckpt/c3.jsonl.
Design: each line gets ONE latent class; its words' features (prefix-2 'p', suffix-2 's', both 'ps', glyph bigrams 'b', whole word 'w') are emitted i.i.d. from that class (EM, K = 30 / 100 / 300). The MAP class of each line is its token, so the compressor learns its own consensus instead of using a fixed rule. 15 fits per corpus; each fit repeated on the page-word-shuffled twin. Streams scored with 60 within-page line shuffles (full) and 40 (odd/even halves).
