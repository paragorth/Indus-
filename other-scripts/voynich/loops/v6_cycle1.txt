# Statistic: for consecutive cells along the order, MI of junction (last glyph -> next first glyph), word class (words >= 10 tokens, else
# first+last glyph), first-first glyph; and same-word / same-2-glyph-prefix rates. Excess over (i) 'full' null: all words of the paragraph
# permuted across cells (common baseline for all orders); (ii) order-specific null: words permuted within each line for row/boustro,
# lines permuted within the paragraph (keeps row content) for col/diagonal/spiral. 20 reps each.
# Controls: verbose-encoded Latin (Caesar+Descartes; each letter -> 1-3 of 12 symbols) written into the SAME 742 paragraph shapes along
# row (negative: prose), col, diag_dr, spiral (positives).
