# v23 cycle 3 -- arrows in the dark: 6,000 random directional probes per corpus (tools/v23_cycle3.py, v23_report3.py;
# data/v23_ckpt/c3_*.json, report3.txt). A probe = (level, random class map, lag, ordered class pair a,b);
# per page D = #(a..b at lag k) - #(b..a); reversal negates D. Levels: glyph stream (random glyph partitions, lag 1-6),
# words within lines (random partitions of word TYPES, or of first glyph / last glyph / length / frequency, lag 1-4),
# line chains within paragraphs (first-word and last-word chains, lag 1-2). Pages split into discovery and held-out
# halves; survivor = |z_A| >= 3 and z_B >= 2 in the predicted direction. Null = same corpus with each page read in a
# random direction (exact matching); reversible word chain RvW. Values: replicated / probes.
