# v57 cycle 1 - THE INK CLOCK: was the Voynich written in reading order? (tools/v57_lib.py, v57_c1.py; data/v57_ckpt/c1.json, git-ignored)
# Prior art check: the brief's "where the pen ran dry" was largely done in v18 (dip proxies vs text resets). Web search: re-inking weight described qualitatively (Stolfi notes 075, retouching notes; voynich.ninja); no test of writing ORDER from ink fade found. So v57 inverts the question: use the fade as a clock to recover the order of writing, then (cycles 2-4) localise re-dips below word level, which v18 could not.
# Data: v18 per-word ink (25 Voynich text pages, f58r-v, f103r-f116r, 11,599 words; 28 Latin CREMMA pages, 9,583 words), residualised per page (quadratic plane) and for glyph content (ridge), z per page.
