# Change of medium: pages are islands and word types are species. Diamond's checkerboard test from community ecology asks which species
#   pairs share fewer islands than fixed island sizes and fixed species frequencies allow (curveball swap null, both margins kept,
#   swaps only inside a stratum = section x Currier language). Alternatives of one attribute (perennial / annual, hot / cold, one colour
#   per plant) should form checkerboard sets in a text that names things; copying and spelling habit make attraction.
# Random guessing: per corpus x unit (page, paragraph) x representation (whole, core, frame): 20,000 random 2-4 word sets + 5,000 greedy
#   sets from random seeds, scored on train units (mean pairwise exclusion z, 40 curveball samples); the 50 best disjoint sets re-scored
#   on held-out units against the held-out pair distribution. Tools: tools/v93_ex.py, v93_c2.py, v93_c2_report.py; checkpoints data/v93_ckpt/c2_*.json.
