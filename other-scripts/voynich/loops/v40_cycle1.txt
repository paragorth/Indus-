# v40 cycle 1 - THE PAGE CHOOSES THE TWIN? Which family of predictors decides each twin choice (4 Oct 2026). Tool tools/v40_cycle1.py (+ v40_lib.py); checkpoint data/v40_ckpt/cycle1*.json, c1_*.out.
# Prior art checked: p/f and the ornate gallows sit in paragraph-first lines (known, Currier and forum: 'vertical room above'); nobody has set layout against word identity, glyph context and pen state as competing predictors of each twin choice under one held-out model.
# Method: one logistic model per twin pair; predictor families SCRIBE (hand, section, language), CTX (glyph before/after, slot position in word), FRAME (whole word with the slot masked = word identity), LAYOUT (tall glyph directly above (+-1, +-3 glyph offsets) in the previous line, same-pair glyph above, x position, offset, distance to line end, word index, line in paragraph/page, paragraph-first/last, line length, recto), PEN (previous choice of the same pair in this line / previous line). Held-out: page-grouped 5-fold; unique gain = log-loss (bits/token) lost when the family is dropped from the full model. Null: 10 permutations of the choice within (frame x hand) strata.
