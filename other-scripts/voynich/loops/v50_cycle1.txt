# Novelty check (web, 4 Oct 2026): steganography / null text in the Voynich is discussed only in passing (voynich.ninja threads 3140, 4514/4515: 'no thread devoted to steganography'); the v6 loop here already compared dense whole-page orders (columns, diagonals, spiral, boustrophedon) and found only the left-margin first-glyph chain. Not found anywhere: a search over millions of SPARSE reading paths (every n-th word, knight moves, two-move cycles, glyph-offset columns, paragraph-keyed restarts, glyph selectors) with planted sparse messages as positive controls and a search-size-corrected null. That is what v50 adds.
# Page grid: ZL3b paragraph lines (ltype P), 207 pages with >= 4 lines, 4,130 lines. Cell = word (W) or glyph at character offset (X). Path = selector (first / last / 2nd / penultimate glyph, top-63 word id, word hash mod 64) x start rule (one path per page; restart per line; restart per paragraph) x left/right origin x edge rule (wrap, row-major overflow, skip, boustrophedon) x start column x a cycle of 1-2 moves (0-3 lines down, -4..+12 columns). 1,668,328 paths; a path never reads a cell twice (added after a first run showed looping paths scoring as artefacts); stream capped at 3,000 units (whole pages).
# Score D = lag-1 mutual information of the path's unit stream minus that of the same stream shuffled within pages. z = (D_set - mean D over 3 line-shuffled replicates) / sd (pooled within family x length bins, never below the path's own replicate spread). Search-size null: the max z when a 4th line-shuffled replicate plays the real pages (REAL 5.73, MK 5.71) and the max z of the message-free Markov filler MK (6.08). Threshold T = 6.08.
