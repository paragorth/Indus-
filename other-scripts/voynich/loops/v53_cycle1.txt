# v53 EVOLVE THE MACHINE THAT WROTE IT: cycle 1, planted control (5 Oct 2026; tools/v53_lib.py, v53_run.py, v53_analyze.py; data/v53_ckpt/run_planted.json, ana_planted.json/.out)
Prior art checked: GA searches for glyph-to-phoneme maps on the zodiac labels and GA phrase analysis (julianbunn.org), the hand-built Naibbe verbose cipher (Greshko 2025, LITERATURE.md item 10), the R2 random/evolved program search (description length, generation not encoding) and the v26 evolved scribe (generator, no plaintext). None evolves the encoding procedure itself over real plaintexts with a measured decodability constraint and a language posterior, so the loop was run.
Program space: segmentation (letter / CV syllable / VC chunk / letter pair) + abbreviation (none, consonant skeleton, truncate 4/6, suspension) + in-word reorder (reverse, rotate, odd-even) + wording (keep words, one unit per word, regroup 2/3, split at 4) + table kind (single, positional I/M/F/S, homophonic 2/3 chosen by the previous glyph, 2/3 tables rotating by line number = table-and-grille, two-piece pair code, line-position table) + up to 5 ordered decoration ops (prefix, suffix, filler word every n words, line-initial marker, line-final marker; each chosen from 1-3 reserved pieces by previous glyph, line position, own first glyph or constant) + line width. Tables are rank-matched from plaintext unit frequencies to the target's own glyph pieces (BPE 0/25/60/150 merges, recomputed after the program's padding is stripped). Every program has an exact decoder (strip reserved padding, DP parse over its own codewords); decodability is measured (decode(encode(x)) vs x) and penalised below 0.85. Fitness = mean log(1+|z|) over 15 statistics (word-length, glyph, first-glyph and last-glyph distributions; h2, x4-style glyph-pair irreversibility, line-first and line-last glyph MI, junction MI, adjacent and in-line repeats, TTR, hapax share, words per line, mean word length) + decodability and information-loss penalties.
Plaintexts (9): DE_herb (Bavarian natural-history/herbal, ReF), DE_rel (Alemannic religious, ReF), IT_med (15th-c. Italian medical recipes, CATMuS), IT_verse (Commedia mss, CATMuS), IT_herb (Brumati herbal), LA_ency (Isidore, natural books), LA_verse (Martial mss, CATMuS), CS_chron (Old Czech Dalimil, old orthography), HE_law (Mishneh Torah). Occitan not available (Wikisource API rate-limited); German/Italian/Latin/Czech/Hebrew covered. Genre is confounded with language for most corpora.
Budget: 9 corpora x 2 seeds x 400 programs x 8 generations = 57,600 programs scored; top 40 per run re-scored on the held-out target half with a fresh plaintext stretch.
