v72 THE CRACK ATTEMPT, cycle 1 (6 Oct 2026): one explicit two-layer model of the writing system; is the message layer needed?
Scripts: tools/v72_lib.py (model, plants, extraction rules, generators, payload model), tools/v72_c1.py, tools/v72_c1_report.py. Checkpoints: data/v72_ckpt/c1/ (git-ignored).
Prior-art check (6 Oct 2026): FINDINGS/STRATEGIES have the separate pieces (v52 edges/middles, v54 variant slots, v61 sealed lines, v59 shared beginnings, v63 l/y pairs, v68 line-initial pool) but no single generative model with a message layer scored against the same model with that layer replaced by noise or a generator. Web: voynich.ninja threads discuss hiding a plaintext 'payload' inside a generator with null glyphs, and a Zenodo 'round-trip encoding' paper reports a 21-symbol alphabet with 18 word-initial classes; neither tests a message layer on held-out pages against generators and planted texts.
THE MODEL. Message layer: a sequence of payload tokens per page. Surface layer S(p, context): ch~sh (C), k~t (G), p~f (H) chosen by a line-reset run habit and line position; benched gallows = ch + gallows; padding e/ee/d/ed after gallows or ch and before final y; optional q- (likelier after a -y word: the junction pairing); line machinery (a y/s/d/t marker glyph on some line-initial words, p/f on paragraph starts, -n written -m at line end); lines sealed (the payload model never conditions across a line break). Extraction rules (inverse maps): E0 identity; E1 padding (drop q-, sh=ch, bench=ch+gallows, k=t, p=f, delete e and d); E1b benches deleted (cth~d); E1c E1 but keep d; E2 E1 + line machinery stripped; E3 E2 + final l=y (v63 pairs); E4 E2 cut to the first 3 payload symbols (v59 beginnings).
PAYLOAD MODEL (held-out bits per payload token, prequential within each page, mixture weights cross-fitted on training pages separately for line-initial / paragraph-first-line / other positions): NOISE = corpus unigram; GEN = unigram + section unigram + line-position unigram + exact copy of one of the last 20 tokens + one-edit variant of one of them (the generator layer: self-citation, copy-and-vary, section and line effects); MSG = GEN + PAGE (exact recurrence from earlier on the page, beyond the 20-token window: topic) + BIG (within-line payload bigram: sequence). MSGSH = MSG with the bigram table trained on section-shuffled payloads (message replaced by noise). EXC = gain(MSG) - gain(MSGSH) = sequence information beyond noise.
Data: discovery half only (even leaves; 104 ZL pages, 17,789 tokens), 3-fold page cross-validation. Generators fitted to the ZL surface: WSHUF (words shuffled within section), MK2 (glyph trigram per section, separate line-initial model), SELFCIT (copy-and-vary, 60% copies), SC10 (copy-and-vary matched to the Voynich, 10% copies), JUNC (v17 junction resynthesis). Planted controls: Brumati's Italian herbal (BRU), Isidore Etymologiae (ISI, Latin), Alemannic German (DEU), each through a payload code (merge: lossy letter -> 11 symbols, Voynich-like word length; verbose: 1-2 symbols) and the planted surface machinery, plus the same generators fitted to each planted surface.
