v81 CYCLE 1 (6 Oct 2026): THE MESSAGE IS IN THE FIRST LETTERS OF WORDS? 3,000 random onset definitions.
Tools: tools/v81_lib.py, v81_c1.py, v81_c1_report.py. Checkpoints: data/v81_ckpt/ (c1_sel_*.pkl, c1_report.json). Two CPU workers.
Onset definition = preprocessing variant (raw; q stripped; q + line markers stripped; e removed; frozen v72 E1c; E1c + line; E1 + line; E1c without gallows; E1c without ch) x onset length 1-3 glyph units x random glyph-class merge (2-12 classes; 30% unmerged). Stream features, line-interior pairs only, each as excess over the larger of two nulls (within-line shuffle of interior words; same-position swap between lines of the page, which keeps the position-in-line law): lag1 (held-out bigram gain), skip (o_i -> o_i+2), beyond_end (onset_i adds to ending_i when predicting onset_i+1), tri, nbr (log ratio of adjacent identical onsets vs within-line shuffle; negative = neighbour avoidance), page (MI page x onset minus cross-page shuffle within section), sec (held-out section-specific unigram gain). J = lag1 + skip + beyond_end. Selection: leaf half 0, page fold 0 -> fold 1; holdout: leaf half 0 -> leaf half 1 (unseen leaves); IT2a as replication.
Controls through the v72 surface machinery (merge code + planted surface): INIT_LA Caesar and INIT_IT Manzoni with each word replaced by its merge-coded initial + a random Voynich E1c tail; ABBR_LA v21 Latin by suspension (first two letters + random tail); INIT_SY the Syon catalogue entries (acrostic-style list) by initials; INIT_SH negative (Caesar initials shuffled over the whole text, same surface); FULL_LA / FULL_IT whole words (Isidore, Brumati); generators SELFCIT, SC10, MK2, JUNC, STACK fitted to ZL3b.
