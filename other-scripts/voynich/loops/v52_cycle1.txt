# v52 THE BOOK IS A DATABASE (cycle 1): massive random field-schema search
# Every word read as a record key cut into 2-5 slots by random cut rules (fixed length from start/end, cut before a random glyph set, run of a random glyph set) with a random slot alphabet (top 6-48 values + OTHER). 2,000 random schemas per corpus scored on half A of pages; top 30 re-tested on held-out half B. Score per slot x external variable = shuffle-corrected MI (page variables permuted across pages, token variables within page), normalised; FIELD SCORE FS = sum over variable groups of the best PURE slot (excess on its group minus leakage to others); DEP = conditional dependence of adjacent slots given the tracked variables. Voynich variables: PAGE group (section, quire, hand, Currier language), POS (label / paragraph-first line / line-initial / line-final / body), NBR (last glyph of previous word, first glyph of next). ZL3b, 38,711 tokens incl. labels. Scripts tools/v52_lib.py, v52_cycle1.py, v52_report.py.
