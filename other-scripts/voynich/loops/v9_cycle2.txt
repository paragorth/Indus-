# v9 cycle 2: richer turning rule (R2), one-disc whole-word volvelle, within-line shuffle null

Script: tools/v9_cycle2.py; report: tools/v9_report.py 2. Checkpoints: data/results/v9/c2_*.pkl.
Same corpora, parse, page split and search as cycle 1 (population Baum-Welch: 4 starts x 40 iterations, best x 120, then
hardened). Bits/token are held-out (17.3k tokens); gains are against the matching no-sequence baseline.

Cycle verdict: no turning rule tried (constant-step-type kernel R1, previous-word-dependent kernel R2, three independent rings
or one whole-word disc) gives a Voynich volvelle that beats chance, let alone a Markov model; the same rules on planted
volvelle text gain ~1 b/tok. The only structure a hidden cyclic state picks up in the Voynich is line-level make-up, which
survives within-line shuffling and so is not produced by turning between words.
