# Pages of each hand dealt into X1, X2 (N tokens each) and a rest; reference = order-2 glyph Markov on the rests of both hands (canon level). Residual r_S(w) = log2((c+0.5)/(n p_ref + 0.5)) over band types (pooled count >= 2, not top-30) plus the 200 likeliest reference words (gaps). within = r(X1,X2), r(Y1,Y2); cross = the four X-Y pairings. Null = the same on per-hand glyph Markov texts (order 2 primary, order 3 secondary). 20 splits. Planted: PRIVr/SHAREDr = finite dictionary of Markov words with random ranks (frequency independent of shape), PRIVm/SHAREDm = ranks by Markov likelihood; private = one per hand, shared = one for both.
