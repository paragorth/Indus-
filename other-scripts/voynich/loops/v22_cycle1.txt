# Model: an S-stage left-to-right "program" (stay / +1 / +2, start in stage 0, end anywhere) whose stages emit word

# (5-fold by page) log-likelihood, millibits per token, gain over the position-free model M0 = P(class | line position).
# All models are conditioned on line position (line-initial / middle / line-final), so line-edge effects are not "program".
# Word class: joint (first unit x last unit), 8 x 6 = 48 classes. Rigid competitors: relative-position bins (2-8), line-index
# bins, head/body/tail (first line / body bins / last line), linear drift. Order-free competitor: paragraph mixture (K 2-8).
# Corpora: ZL3b paragraphs >= 12 words (712 paragraphs, 34,531 tokens); Latin Isidore Etym. XVI-XVII paragraphs (435);
# Italian Brumati herbal paragraphs (407). Nulls: lines shuffled within paragraph; lines 2..n shuffled (head kept);
# words shuffled within paragraph among slots of the same line position; v21 F3 Markov resynthesis. Plants: 4-stage elastic
