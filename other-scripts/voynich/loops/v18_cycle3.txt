# v18 cycle 3: are the detected dips real pen events (ink budget), and is a pen-load internally coherent? (tools/v18_cycle3.py; data/results/v18/c3.json)
# (a) A quill holds a roughly fixed load, so true dip-to-dip intervals should be more regular in ink spent (or pen travel) than random marks. CV of intervals in words, glyphs, ink pixels and pen travel (sum of word widths), mean over the 1,008 primary settings, vs pseudo-dips at random positions (same count per page, same minimum spacing, 5 draws per setting).
# (b) Pen-load coherence: if a table, grille or generator state is consulted once per load, words written on the same load should resemble each other more than words the same distance apart that straddle a dip. Same-line word pairs at distance 2-4; similarity = same first glyph / same last glyph / edit similarity (difflib ratio) / same length; statistic = within-load minus straddling, distance-stratified, mean over primary settings; null = page-swap surrogates. Planted: Voynich-like text whose generator draws a fresh 'theme' (preferred first glyph, weight e^kappa) at every canonical dip (20% shifted +-1).
