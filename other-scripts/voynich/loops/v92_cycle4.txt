# v92 cycle 4 (7 Oct 2026): K3' TRANSPLANT BY SPELLING. Are the page-recurring frames arbitrary labels (names) or the page's own spelling?
# VOY_MODE=glyph. Tools: tools/v92_c4.py (phase A = selection on train folios, phase B = one held-out test), tools/v92_sum4.py;
#   checkpoints data/v92_ckpt/c4A_*.json, c4_*.json. Frozen: data/v92_frozen_predictions.json
#   (sha256 c2f77630ed89e4389f66785df41e19576d90c43af65d3ddb0fa439519740389b), written after phase A and before phase B.
# Idea (inverts K1): a name is an arbitrary label, so the spelling of the rest of a page should not tell which page a set of recurring
#   names came from (beyond section and hand). A spelling mood writes its recurring words in the page's own glyphs. For each random view
#   (glyph unigrams / bigrams / first-and-last-3 positional glyphs / both; optional random glyph merge classes; optional ends dropped; unit
#   word or frame; rarity band; minimum lines; smoothing), each page's recurring units are scored against the glyph log-ratio profile of
#   every same-group page, built from that page's words with all its own recurring units removed. Accuracy = mean normalised rank of the
#   true page (0.5 chance). 1,500 random views x 13 corpora (about 17,000 scored); top 20 per corpus tested once on held-out folios
#   against 200 within-group relabellings; 'far' = only candidate pages more than 4 pages away (removes neighbour drift).
# Novelty check: v84 (T_form: burst words spelled alike) and v40 (the page chooses the twin) measured page spelling preferences; neither
#   asked whether the page's REPEATED words can be put back on their page from the spelling of its OTHER words, against real named texts.
