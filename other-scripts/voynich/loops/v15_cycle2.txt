# v15 cycle 2: massive random codebooks + annealing on the length channels
# Tool: tools/v15_cycle2.py (report: tools/v15_report2.py); per-cell JSON + _summary.json in data/results/v15/cycle2/
# 350 cells = sources x channel x scheme x language; ~2,600 solver runs; each run scores 2,000 random codebooks, anneals the best 3
#   (heat-bath sweeps over every symbol, 12 sweeps) on the first half, then scores the key on the held-out second half:
#   J = mean log2 P(letter | 2 previous) - 1.0 x KL(decoded letter mix || language letter mix)  (the KL term stops the 'iiiii' collapse
#   that a pure trigram score rewards). In all, ~5 million random codebooks scored, ~7,800 annealing chains.
# Letter models (trigram, add-0.1): Latin (Isidore), Italian (Dante), German (Kafka), Old Czech (Dalimil), Hebrew (Genesis+Exodus,
#   Sefaria, points stripped), Occitan (wikisource.org Category:Occitan, 162 pages), Ancient Greek (Iliad, Perseus).
# Schemes: len (length 1..10 -> letter), pair (two lengths -> letter, 81 homophones), bacon2 (5 parity bits -> letter),
#   baconT (5 short/long bits), tri3 (3 trits of length mod 3), mod4pair (two lengths mod 4). Channels: glyph units, EVA characters,
#   pen strokes (rank-binned for len/pair); ZL ',' vs '.' gaps (5 bits -> letter); words per line.
# Nulls (the same search): words shuffled within line (6-8x per cell; keeps every glyph statistic) and the whole stream shuffled (2-4x).
