# chain, reduplication, local copy-and-vary (window 1-8 lines or page, weights one line up / 2+ lines up, edit rate), page urn

# last unit echoing the word above, paragraph drift (previous line's share of q-, a-, l- words), one-m/g-per-line, word-length
# autocorrelation; line-width filling. Every mechanism reads only observable history, so the same code samples and scores text.
