# v29 cycle 1 - FEATURES SPREAD? Blind search for stroke features that agree within words (harmony) or across word junctions (4 Oct 2026).
# Tools: tools/v29_lib.py (feature generator, tier statistics, Markov-2 and word-shuffle nulls, max-statistic), v29_cycle1.py, v29_report.py. Checkpoints data/v29_ckpt/c1_*.pkl (git-ignored).
# Prior work: forum remarks that Voynichese "shows no vowel harmony" (goodreads 'Voynich Reconsidered' blog; voynich.ninja), no test, no controls, no stroke features. New here: thousands of random stroke features, tier (skip-transparent) agreement at distance 1-3, junction agreement, direction index, Markov-2 and max-statistic nulls, harmony-language and planted controls.
# Feature = (tier, value): tier = glyphs having a random conjunction of 0-3 stroke primitives (v25 decomposition), value = a stroke primitive or a pair (or/and/andnot). Per corpus ~1,600 stroke features + 400 random glyph-class features (Voynich); ~1,100 phonological-feature + 200 class features (controls). Statistic = phi between the values of two tier members (tier1-3 = next 1-3 tier members in the word, raw3 = tier glyphs exactly 3 apart, junc = last tier member of a word vs first of the next word on the line, dir = agree(last two) - agree(first two) in words with >= 3 tier members, > 0 = left-to-right). Excess = phi - mean of 10 nulls (Markov-2 glyph-trigram resynthesis within words; within-line word shuffle for junc). z uses sd floor 0.02. Search correction: leave-one-out max z over the whole search on each null replicate (max of 10 = threshold). ~150k glyphs per corpus (Czech 117k).
