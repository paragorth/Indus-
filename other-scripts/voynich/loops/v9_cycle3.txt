# v9 cycle 3: does the best volvelle reproduce the Voynich LINE structure? (+ cycle 3b controls)

Scripts: tools/v9_cycle3.py (generation + line statistics), tools/v9_cycle3b.py (planted one-disc control, IT2a check).
Checkpoints: data/results/v9/c3_*.pkl, c3b_*.pkl. Each fitted model generates text with the held-out Voynich line lengths
(10 replicates; means shown; replicate sd <= 0.009 for MI/JSD, <= 0.035 for CLUMP). Statistics in filler space (prefix/core/suffix symbols):
J_in = MI(suffix of word t; prefix of word t+1) inside lines; J_brk = same across the line break; OPEN = JSD(prefix of
line-first word || others); CLOSE = JSD(suffix of line-last word || others); WW = MI(prefix; suffix) inside a word;
CLUMP = per-line count of the commonest prefix, variance / binomial variance. MI = plug-in minus shuffle mean.
Models: V1 best cycle-1 volvelle (rule R1, reset), V2 cycle-2 volvelle (rule R2), MX per-ring Markov-1 x previous suffix,
W2 word trigram on filler tuples.

Cycle verdict: even granting the volvelle its best fitted rings and rule, text dialled from it lacks three of the five Voynich
line features (junction coupling inside lines, within-word prefix-suffix agreement, line-end vocabulary); it only reproduces
the line-start effect and the break in coupling, both of which follow from any per-line reset.
