v78 cycle 2 (6 Oct 2026): THOUSANDS OF RANDOM MECHANISM MIXTURES fitted to the doubles' fingerprint, held-out leaves. Scripts: tools/v78_c2.py, v78_c2_report.py (operators in v78_lib.py). Checkpoints data/v78_ckpt/c2b*. Two CPU workers.
Method: for each corpus, base = its discovery leaves (leaf parity 0) with every within-line double collapsed. Random mixtures of six operators (each on with p 0.5, log-uniform rates): CHANCE (a token followed by an independent re-spelled token of the same type, prob ~ frequency), REDUP (a random lexical class doubled, rarely tripled, re-spelled), LIST (ditto at line-first / second / line-final / paragraph-first positions, runs), DITTOG (a token repeated with the identical glyphs, part across the line break), TALLY (1-3 of the 80 commonest types expanded into runs 2, 3, 4, ...), GEN (a token replaced by a copy of one of the last W words of the page, one glyph changed with prob m). 18-feature fingerprint (rate, lag-1 spike, near-copy spike and ratio, re-spelling, lag-1 vs lag-2/3 type divergence and re-spelling difference, runs >= 3, line positions first/second/last, paragraph-first line, cross-line repeats, frequency, concentration and length of doubled types, page dispersion, type recurrence across pages). Accept the nearest 3%; posterior share of the doubles written by each operator; held-out: accepted mixtures re-run on the held-out leaves vs 200 prior mixtures. Voynich 2 x 2,500 runs + 2 x 275 held-out; 15 controls x 800 + 224 = 50,000 simulated texts. Groups: VISUAL copy = DITTOG + GEN; MEANING-level = REDUP + LIST + TALLY; CHANCE.
A first run (c2voy/c2ctl, run1 logs kept) restricted tally types to <= 3 payload symbols; the planted tally unit is a 5-symbol word, so the prior could not express it (TALLY share 0.002). Fixed (any of the 80 commonest types) and everything re-run; only the re-run is reported.
