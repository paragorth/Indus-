# v16 'THE SPACES ARE LIES' - cycle 1: massive random search over mechanical re-spacing rules (tools/v16_cycle1.py, v16_lib.py, v16_report1.py; results data/results/v16/cycle1/)
# Objective MDL2 = adaptive Chinese-restaurant code for the unit sequence + lexicon spelled once with an adaptive glyph-bigram code (a proper code; the flat-spelling MDL was rejected because it preferred 2-glyph chunks over true Latin words, so it failed the negative control before any Voynich run).
# Rules selected on even lines (train), scored on odd lines (test). 8,000 random rules per corpus (80,000 in all), 13 rule families: before glyph set X, after set Y, before+after, break between a glyph-pair set, every k glyphs, shift every space by d, jitter, drop/insert, random density, keep only spaces after Y / before X, written plus breaks before X / after Y; each with a min-unit-length filter 1-3.
# Prior art checked: unsupervised (BPE) re-segmentation of space-free Voynich recovers ~90% of the written word edges (voynich.ninja thread 5049); 'spaces inserted by rule' has been suggested on forums. No calibrated MDL rule search with planted and null controls was found.
