v79 THE LINE-START CHAIN AS A SEPARATE CHANNEL, cycle 1: COUNTER, CALENDAR COLUMN OR PERIODIC TAG? (6 Oct 2026). Scripts: tools/v79_lib.py, v79_c1.py, v79_c1b.py, v79_c1_report.py. Checkpoints: data/v79_ckpt/ (git-ignored). Two CPU workers. v76 and v78 running, not duplicated.
Idea (arrow in the dark): the line-initial glyph chain (v6/v10, C+ after v77) is not text but a non-linguistic margin channel of the kind medieval books carry (line/verse numbers, entry numbers, calendar letters and golden numbers, periodic tags). v10 killed a plain counter (fixed cyclic order over ALL lines) and a modular line count; new here: massive random search over SPARSE counters (only lines whose glyph is in a digit set D count; the rest are padding), any digit set and order, any step (golden-number-like +8 jumps included), three reset units, entry counters on paragraph-first lines, periodic tags beyond positional drift, and calibration on REAL channels written into an opaque Voynich-like surface.
Prior art (web, 6 Oct 2026): 'vertical Neal keys' and 'index column' speculations (ciphermysteries, voynich.ninja); no calibrated test against real numbering/calendar channels was found.
Chain = first glyph of each body line (paragraph-first lines excluded except in the entry unit); top-10 alphabet per corpus; discovery/held-out = leaf parity (both ways, averaged).
Controls (all through the v72 verbose code + v72 surface; the channel glyph replaces the surface's own line-start marker on 70-90% of lines; 10 opaque digit glyphs drawn from the Voynich line-initial pool): C_DANTE = real verse numbering of the Commedia (units digit, 4080 lines, canto reset, page breaks not resets); C_DOM = a 4-year Julian calendar, one line per day, the dominical (ferial) letter a-g; C_GOLD = the same calendar's golden-number column (units digit, numbers +8 mod 19, ~1/3 of days blank); C_ENTRY = Brumati Flora, running entry number on each entry's first line; N_ISI = Isidore with only the v72 surface's own anti-repeat marker (y/s/d/t, never the previous one); generators SELFCIT, SC10, MK2, JUNC, STACK fitted to ZL3b.
