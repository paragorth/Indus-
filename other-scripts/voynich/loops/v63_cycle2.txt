v63 cycle 2 (5 Oct 2026): slip operators by massive random guessing (tools/v63_c2.py, v63_c2b.py; data/v63_ckpt/c2.log, c2b.log, c2_results.json, c2b_ops.json)
Each adjacent pair within a paragraph at glyph edit distance 1-2 gets the edit script turning the second word into the first (A = op(B): substitution,
insertion, deletion tagged initial/medial/final; TRUNCk = false start). Ordered slips make c(op) > c(op^-1); order-free text makes them equal.
Hypothesis = a set of oriented operators; score = sum(c(op) - c(op^-1)) / sqrt(sum(c(op) + c(op^-1))). Per run: 20,000 random sets of 1-24 operators
+ greedy top-K, chosen on half the folios, scored on the other half, 10 random splits (about 200,000 hypotheses per corpus, about 4 million in all, nulls and controls included).
