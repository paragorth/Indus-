# Change from cycle 1 (which failed calibration): hypotheses are no longer chosen by compactness. 4,000 random hypotheses per corpus = anchor scheme x random partition of the 7 fields into 2-4 wheels x a random 'slot alphabet' per field (50%: glyph values merged into 2-8 random concept classes, i.e. homophone groups; 50%: kept). 5,400-6,600 multi-field wheels per corpus. Stage 1 (train folios): rare-value own-page recurrence z; top 200 -> stage 2 (train folios): CONJUNCTION z = own-page recurrence of the wheel's rare combinations (hits - expected from same-stratum pages) in the real text minus the same in within-page field shuffles (each field permuted separately inside the page: keeps the page's spelling habit per field, breaks which values are combined in one word), 4 shuffles; top 20 -> TEST folios with 16 shuffles. Call = test conjunction z >= 3 and lift >= 1.3.
# Plants (carriers = Voynich words shuffled within hand+section; f1 drifts smoothly in all): C_HERB3 = Konrad's plants, one entry per page, content words -> 3 Lullian letters (18-letter alphabet) at f2, l2, f3; C_ASTR3 = Hyginus, one entry per paragraph, same code; C_HERBH = Konrad, 2 letters (f2, l2), each letter written with one of two homophones at random; HABIT3 / HABITH = the same slots filled from smoothly drifting page distributions (no content). Kills: SHUF0/SHUF1 (positions shuffled within hand+section), MARK (glyph Markov-2 per section x hand).
