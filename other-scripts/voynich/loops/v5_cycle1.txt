# v5 cycle 1 -- "not language but notation": cadence and mode-final fingerprints
# Hypothesis under test (arrow in the dark): each line is a musical/temporal phrase, each glyph a note.
# Scripts: tools/v5_corpora.py (all corpora), tools/v5_cycle1.py, tools/v5_cycle1b.py; results data/results/v5_cycle1*.json
# Corpora: Voynich ZL3b and IT2a paragraphs (P lines, glyph units); GregoBase Gregorian chant (dump 2019-10-24 via
#   github.com/bacor/gregobasecorpus commit ad5060fe, CC0; 1,500 of 5,840 de-duplicated pieces with mode 1-8;
#   symbol = staff letter as written, word = syllable's notes, line = phrase between full bars); Caesar, Manzoni,
#   Dante under a fixed verbose substitution (1-3 symbols per letter); Voynich with glyphs shuffled inside lines;
#   Voynich words regenerated by a glyph-trigram model (same word counts).
# Novelty check (web, 4 Oct 2026): the music idea is old forum talk (voynich.ninja thread 3968, 2023: "no quantitative
#   tests were run"; thread 5724 'cadence-based artifact', no tests). No study found that runs mode-final, metre or
#   transposition statistics against a real chant-notation corpus. These tests appear to be new.
