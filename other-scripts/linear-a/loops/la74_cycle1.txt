Model (tools/la74_common.py): a vessel set = k = 2-6 vessels, sizes v1 > ... > vk in units of the integer unit (v1 0.15-0.95, adjacent ratios log-uniform 1.25-10), mapped to k fraction signs; pouring habits: share u of continuous remainders vs 'intended' c x one vessel (c <= cmax), probability g of going on to the next vessel after using one, round-up threshold rho for the leftover. 20,000 simulated pourings give a distribution over vessel strings (largest first). A real string is scored by P_V = (1-e) P_H + e P_NV, where P_NV is a fitted no-vessel model (plain random fractions: number of distinct signs, unigram signs, canonical order from train, geometric repeats). Gain = nats per string over P_NV on HELD-OUT documents (50/50 document split). Search: 2,000 random vessel sets per corpus with a hill-climbed sign mapping, top 20 refined by 120 annealing steps (common random numbers), then scored once on the held-out half. Scripts tools/la74_c1.py, la74_lookup.py; checkpoints data/la74_ckpt/ (git-ignored).
