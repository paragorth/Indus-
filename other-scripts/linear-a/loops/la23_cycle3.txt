# LA-23 cycle 3: massive random guessing of the population size (rejection ABC with local-linear adjustment; tools/la23_c3.py; outputs data/la23_ckpt/c3_*.json, c3_*.log, reference tables c3_ref_*.json, git-ignored)
Each guess = a random population (N log-uniform 30-20,000; capture heterogeneity sigma U(0,2); locality to Villa vs Casa U(0,.95); homonym rate U(0,.3); variant-spelling rate U(0,.2)) written onto the real tablet frame (each HT tablet keeps its number of person-like slots and its archive). 30,000 guesses for HT per word set, 10,000 per LB draw (6 draws): ~110,000 simulated archives. Summaries: names seen, captures, names on 1 / 2 / 3+ tablets, names in Villa, Casa, both. Nearest 1 % kept.
