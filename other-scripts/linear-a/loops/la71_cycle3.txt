| LA-71.3a | Make the parser the default. la71_parse.load(ver='rd') is the loader for new loops ('read' = robustness check, 'all' = legacy). la60_common.load_la (base of la60-la70 and la67_lib) now loads 'rd' unless LA71_VERSION=all (cache la_docs_rd.json beside the legacy la_docs.json); removed tokens appear as ['X', kind, section word] so a section that loses a number is untestable. build_corpus.py: the U+1076B comment corrected (break mark, not line continuation) and corpus.json declared legacy, kept byte-identical so earlier loops reproduce. tools/la71_run.py runs any older script on any version without touching the repo. Rule for future loops: report rd as the primary run and read as the check; quote 'all' only to compare with pre-la71 numbers. |
