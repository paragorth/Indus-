# LA-8 cycle 1: let evolution write the grammar (strict description length)
# Machines: typed-slot probabilistic automata. Each lexicon type (count >= 2) is put in one word class. Each novel-word key (kind, plus last sign for multi-sign words) is put in one class, which makes that class OPEN. Each class has 1-3 hidden states (slots). Transitions are fit by Baum-Welch.
# Fitness = held-out bits (2-fold CV by document) + description length (DL). GP: mu 16, lambda 32, tournament 3, 1-5 mutations (move, guided neighbour move, key move, merge, split, slot +/-1, block move), random restart after 250 stalled generations.
# Corpora are size-matched to Linear A admin (3,935 tokens): LB = DAMOS docs sampled to 3,945 tokens; PE = 3,945 tokens (sign-level); LAS = LA shuffled inside each document; PFLAT/PREC = planted.
# No Linear B sound values are used anywhere. Sign transliterations are identifiers only.
| id | method and control | result | verdict |
|---|---|---|---|
| LA-8.1a | Planted control, strict DL (every lexicon type pays log2 K bits for its class label). PFLAT is a known flat form: HEAD (5, closed), NAME (open), LOGO (6, closed), NUM, FRAC, TOTAL (2, closed). 1 seed, 2,500 generations, 80,000 evaluations. | Evolved K=5 (truth 6), 1 open class (truth 1). ARI vs the true classes = 0.953 (token-weighted). Fitness 20,302 vs 20,649 for the true genome, so the GP beat the generator's own partition: it merged TOTAL into HEAD. 1 loop, NAME -> NUM -> NAME. | PASS: the method recovers a planted form. |
| LA-8.1b | Planted control, strict DL. PREC is a small language with centre-embedding relative clauses: DET, REL, P closed; N and V open (suffix-marked); NUM. Same compute. | K=5 (truth 6), open 3 (truth 3), ARI 0.933, fitness 29,381 vs truth 29,449. | PASS: open classes and suffix-keyed classes are recovered. |

LB K=3. PE K=2. LAS K=2. Held-out bits/token: LA 7.88, LAS 8.12, LB 9.19, PE 6.54. | Under strict DL, about 4,000 tokens cannot pay for more than 2-3 classes in any real corpus.
