LA-60 THE CRACK ATTEMPT, cycle 1: the working reading as a generative grammar of whole documents
(tools/la60_common.py, la60_model.py, la60_c1.py, la60_report1.py; checkpoints data/la60_ckpt/c1_*.json)

THE READING (PRIOR, assembled from FINDINGS.md; 51 lexicon statements + order + site defaults)
  TOT    KU-RO, PO-TO-KU-RO (total; running total allowed, la56 HT 127b)            A
  RES    KI-RO (residue or sub-heading)                                              B
  COM    logograms; VIN OLE OLIV VIR GRA CYP; single signs NI KI DI RE TI MA (la45); *304 *308 *306 E SU (la8/la49); *307 (la20 C)   B (C for the last six)
  HDR    single heading signs *301 KA KU SI RO ZE TE A I TA O JA DA *164 *411-VS U (la45, la49, la28, la40)   B
  TRX    heading/transaction words SA-RA2 PA-DE A-DU KA-PA KU-PA A-PA-RA-NE MA-KA-RI-TE *516 KU-NI-SU KU-RE KA-NA (la8, la53, la40)   B/C
  CENT   OLE+U, OLE+MI, OLE+DI are entries, not commodities (la45)                   C
  ORDER  CYP = GRA = *307 < NI < VIR = OLE < OLIV = VIN = QA2 (la20 A, la46 B, la50 C)
  SITE   default commodity KH CYP, ZA/ARKH GRA (la54)                                  B (negative-ish)
  LIB    libation-formula words form a separate register (la17, la29, la51)           B
  Layout totals on their own bottom line, headers at line starts (la47) are not used in the likelihood (layout carries ~0 bits beyond order, la47).
INDUCED: the same kinds of statement from fixed corpus-agnostic rules on the TRAINING half only
  (total = word whose number closes the running sum in >= 2 cases and >= 20 %; COM = single signs
  with a number >= 60 % on logogram documents; HDR = single signs with a number <= 35 %; TRX =
  multi-sign words that open >= 50 % of their lists; order = Bradley-Terry; site default = mode).
  On LA it finds KU-RO in 8/10 halves (once *21M instead, once nothing), 22-38 statements.

MODELS (all predict the same events: every token's kind and identity, every number's integer and fraction string)
  B0 unigram; B1 Witten-Bell trigram over symbols; G0 = the grammar with an EMPTY reading (roles = kind:
  logogram / single-sign word / multi-sign word / number / line break); G(R) = role trigram x identity
  within role x number given context, + arithmetic (number after TOT = running sum w.p. theta, fitted)
  + commodity order (beta, fitted). Controls: R with roles shuffled among its types (20 per split), the
  same keeping TOT fixed (20), G(R) without arithmetic, without order. 10 site-stratified tablet-level
  splits. Calibration: Linear B KN+PY (DAMOS, sign identities only) at Linear A size, documents drawn
  to match LA's mix of 1 / 2 / 3-5 / 6+ number documents, with INDUCED (same rules) and LBPRIOR (a true
  partial LB reading of the same kind: to-so/to-sa = TOT, o-pe-ro = RES, 21 transaction/heading words,
  order fitted on all LB; calibration only).

Cycle 1 verdict: the reading organises Linear A documents (shuffling it costs 160 bits/half, 10/10),
but as a predictive grammar it adds nothing beyond the surface kinds (logogram / single sign / word /
number) except the KU-RO arithmetic (+36 bits/half, ~0.2 bits per document). A true Linear B partial
reading of the same kind gains 211 bits over the empty grammar at the same size. Grade B.
