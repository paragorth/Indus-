LA-56 cycle 1 (5 Oct 2026). THE SCRIBES' MISTAKES SHOW HOW THEY THOUGHT: random inclusion-rule search on written totals.
Novelty check: LA-9 fitted error MECHANISMS (skip, double, carry, slip, tally, rounding, misread) to KU-RO totals; LA-6.3c described what the first KU-RO counts; LA-12 searched cross-tablet closures; PE-42 did the same error lens for Proto-Elamite. Web search: single-tablet discussions that some entries (e.g. deductions) are left out of KU-RO (https://www.academia.edu/167647758). Not done: attribute-conditioned inclusion rules (which WORDS / signs / commodity / role the scribe left out, subtracted or doubled) scored as thousands of random hypotheses with fraction values as a nuisance and held-out re-test. That is this loop.
Tools: tools/la56_common.py (data, engine), tools/la56_c1.py, tools/la56_report.py. Checkpoints: data/la56_ckpt/c1_*.json, c1_report.txt.
Data: 32 Linear A KU-RO / PO-TO-KU-RO sections (7 close under the default reading for most fraction draws). Each candidate item carries: label word, first and last sign, word length, logogram in force, same/different commodity from the total, fraction letters, position, size class, several numbers on one line; roles main / earlier totals (sub) / after the total / other side / other-side totals. Fraction values: 600 random draws from a 49-value grid shared across the corpus (log marginal likelihood averaged over draws; background 0.05 per section). No Linear B values.
Rules: every single rule whose feature occurs in >= 2 sections (EXCL, NEG, DBL, ONLY commodity, ADD role / role+word), fraction rules (letter ignored, read as a whole unit, read as another letter, all fractions dropped, total's fraction ignored), COUNT (total = number of lines), plus 1,500 random pairs: about 2,000 rules per corpus run, ~70 runs (~140,000 rule-corpus scorings).
Held-out: 12 random tablet-level half splits, best rule picked on one half and scored on the other (both directions); 'replicated' = gain > 1 nat on both halves in >= 6 of 12 splits.
