# LA-25 final: THE FIRE SET THE CLOCK (4 Oct 2026)
# Idea: each LM IB archive was baked by its destruction fire, so its commodity mix is a snapshot of one moment of the
# agricultural year. Fit random agronomic crop calendars x a destruction month per archive (rejection ABC; about
# 1.5x10^7 simulated archive sets over all banks) to document-level commodity profiles (GRA, VIN, OLE, OLIV, other).
# Controls: planted archives (same generator), oracle base rates, Linear B KN/PY (argued spring destruction; month names
# never used), leave-one-out LB transfer, commodity labels shuffled per site, random (non-agronomic) calendars,
# split-half Hagia Triada, archive-size scaling. Tools: tools/la25_common.py, la25_c1.py ... la25_c4.py, la25_c2b.py.

| LA-25.final | Destruction-season clock: 10^5-10^6 random agronomic calendars x destruction month per archive, ABC on commodity profiles of HT, KH, ZA, TY (LA) and KN, PY, TH, MY (LB). Controls as above. | Inferred months (flat posteriors, max 0.10-0.12 vs 0.083; 80% sets 9-10 months): HT MAP Jun / Mar / Nov, KH Aug / Sep / Jun, ZA Aug / Oct / Nov, TY Jan / Jan / Mar (free / transfer s 0.3 / transfer s 1.0): the MAP moves with each setting. Planted LA size, free base rates: true-month mass 0.087-0.094 (chance 0.083), unchanged at 64x size. Oracle base rates: 0.11-0.14, MAP +-1 month 0.5-0.6. LB control: KN, PY spring mass 0.43, 0.36 (core), 0.38, 0.32 (extended); LOO 0.50 (KN), 0.32 (PY); prior 0.33. Shuffled labels as informative or more (P 0.10, 0.76, 0.74). Agronomic vs random calendars P(agro) 0.48-0.52. One fire vs several: P(same) 0.49, calibration AUC 0.52-0.61 (free), 0.64-0.75 (oracle). HT split halves not recognised as simultaneous (0/20; planted gap 0.003). Outside check: no published season for any LM IB fire; the Zakros bowl of preserved olives is the only hint (autumn-winter if fresh). | KILLED (grade A, calibrated negative). No destruction month and no one-season/several-season verdict can be read from the commodity mix: base rates and season are confounded, and more tablets do not help. Grade C, outside the method: Zakros olives as an autumn-winter hint (support: fresh-olive stores in other LM IB fire layers; kill: shown to be cured olives). Lesson: a fire-clock needs an independent anchor (month names, dated intake records, or seasonal plant remains in the same burnt room). |
