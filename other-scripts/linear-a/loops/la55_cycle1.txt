la55 cycle 1 (5 Oct 2026): WORDS GROW LIKE CITIES - scaling classes of every word across archives
Tools: tools/la55_common.py, tools/la55_c1.py, tools/la55_c2b.py. Checkpoints: data/la55_ckpt/c1_*.json, c1*_w*.out.

Idea. In cities, infrastructure grows sublinearly with population and social output superlinearly. If archives
behave the same way, administrative function words saturate (every office needs them once), names grow in
proportion to the number of documents, and specialised goods appear only above a size threshold.
Novelty check: web search finds urban scaling of word use in Twitter by city (R. Soc. Open Sci. 2019,
https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6837183/ ; https://arxiv.org/abs/1903.04329) and Heaps/Herdan scaling in general corpora; nothing on
ancient archives, Linear A or any script. LITERATURE.md, FINDINGS.md and STRATEGIES.md: la5 measured one Heaps
exponent for the whole corpus (LA-5.2a); nobody fitted per-word scaling across archives.

Units ("archives"): Linear A = la51 deposits (35 units >= 3 documents; HT Villa R13 863, Khania Kastelli 219, HT
Villa magazines 72, Knossos 53, sanctuaries 44, Zakros palace 31 ... down to 3); two-sided objects merged.
Linear B = DAMOS find areas at KN, PY, TH, MY, TI, KH (103 units, 3,028 docs); LBS = whole LB units drawn to
Linear A size (59 units, 1,699 docs). Ur III = site x year name (first 3 tokens after 'mu'; year line removed),
12,000-document subset (units >= 3 docs). Words opaque; logograms by their first element.
Per type w (>= 3 documents; Ur III >= 5): beta_w from Poisson log mu_wa = alpha_w + beta_w log N_a (zeros
included); threshold gain (absent below T, proportional above, best T) over proportional; occupancy (units with w).
Each z-scored against 1,000 re-dealings of documents to units (sizes kept): N1 free; N3 within genre (LA support
type, LB site:series letter, Ur III site). N2 = 300 bootstraps of documents inside units (beta intervals).
Fixed class rule (set before Linear A was read): SATURATING beta below null (p<0.05) or occupancy above null;
SUPERLINEAR beta above null; THRESHOLD threshold gain above null; LINEAR otherwise.

Cycle verdict: method passes planted saturation/linearity, fails planted superlinearity; the urban-scaling class
prediction fails its Linear B control (function words do not saturate). Linear A's only robust non-linear words
are staples + KU-RO (saturating) and Khania/HT nodule signs (threshold = locality).
