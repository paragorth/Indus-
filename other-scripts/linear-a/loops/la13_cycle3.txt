# LA-13 cycle 3: does the substitution graph build a sign grid by itself?
Script: tools/la13_c3.py. Output: data/la13/c3_report.txt, c3_fits.json, c3_heldout.json.
Edges: X<->Y for every one-sign-different word-type pair; CROSS = clean cross-site pairs (cycle 1, substitutions only), WITHIN = same-site pairs.
Annealer (150,000 moves) places the 60 highest-degree signs injectively in a 12 x 5 grid to maximise the edge weight joining signs that share
a row or a column. No sound values in fitting; LB values are used only to score the LB control; a post-hoc LA label check is descriptive.
