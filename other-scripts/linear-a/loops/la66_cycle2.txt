la66 cycle 2: per-feature null calibration (6 Oct 2026). Scripts tools/la66_c2.py, la66_c2b.py, la66_sum2.py, la66_sum2b.py; checkpoints data/la66_ckpt/c2_*.json, c2b_*.json, c2_class.json (git-ignored).
Design: real Linear A under 3 split families x 2 document-effect modes (6 runs x 12 splits x 2,000 random models = 144,000 models); 14 null runs (quantities shuffled within document x stratum 4, within commodity 5, word bundles re-dealt within documents 3, signs shuffled across the words of an entry 2); Linear B at LA size; LA with totals kept. Then the SAME 6-run design on two single null corpora and on Linear B (cycle 2b, 17 runs). Rule frozen before scoring: STABLE DESCRIPTOR = descriptor in >= 4 of 6 real runs, one sign, descriptor in <= 1 null run. IDENTIFIER = >= 6 occurrences on >= 3 documents, never a descriptor, |median effect| < 0.1 in every run. ~1.0 million models in cycles 1-2.
