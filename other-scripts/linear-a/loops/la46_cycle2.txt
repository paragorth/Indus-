LA-46 cycle 2: do residues found on one half of the corpus predict the other half better than the forgers do?
Date 5 Oct 2026. Scripts: tools/la46_c2.py, tools/la46_report2.py. Checkpoints data/la46_ckpt/c2_mean_*.json.
Design: 6 random half splits per corpus. On half A only: inside-out contest (40 random architectures, 5-fold, 3
forgeries per held-out doc), residues = relations with P(Poisson(ensemble-mean E) >= R) < 0.01, weight
log((R+.5)/(E+.5)). On half B: 30 FRESH random architectures, trained on A + the other B folds (they see everything
except the scored document, including every residue instance in A), forge each B document once per architecture.
Score: (a) AUC of the residue score sum on real B vs forged B; (b) held-out firing ratio = residue instances in real
B / in forged B (scaled). Controls: an equal-size random weight set from A's tested relations (same families);
worlds W1 (template + cluster + site forger) and W2 (plain order-3 n-gram), shuffled LA (SH1), planted world PL1,
LB1, LB2, UR1 (Ur III).
