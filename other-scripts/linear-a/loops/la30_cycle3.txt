# LA-30 cycle 3 (4 Oct 2026): hidden totals in a hidden currency, anywhere on a tablet (no KU-RO needed).
# Idea: if goods convert at fixed rates, some numbers should be the converted sum of the mixed run of numbers written just
# before them, on tablets that never write KU-RO. This enlarges the constraint set from 32 written totals to 1,685 mixed runs.
# Data: 212 inscriptions with >= 3 numbers; 14 types (base commodity, 'bare' fixed at 1, OTHER); site fraction values.
# Script: tools/la30_c3.py; outputs data/la30_ckpt/c3*.json.
| LA-30.3a | Score = inscriptions with >= 1 exact hit: a number equal to the rate-weighted sum of a run of 2-7 numbers right before it that mixes >= 2 types incl. a commodity. Rates on p/q <= 12. Fit on half the inscriptions (2x10^4 random + 12 annealed chains x 250 steps + Occam reset), held-out hits minus plain-sum hits; 6 splits x 4 reps. Nulls: N1 labels shuffled across all numbers (20), N2 numbers shuffled within each inscription (20). Planted: random rate vector; in 12 % of inscriptions with a mixed run one number replaced by the weighted run sum (10). | Plain sum already hits 15 inscriptions (N1 labels: 14, so these are chance coincidences of small numbers). Real held-out gain -2.13; N1 -3.35 (P 0.19); N2 -1.83 (P 0.52). Planted: -2.48, rates recovered 4/65, above the N1 95th pct in 2/10. The full-fit rates are noise (they come with no held-out gain). |
