# la76 cycle 1: the archive as a market (hidden money of account), massive random search
# Pre-check: the plain idea (one exchange rate per commodity pair, co-listed quantities scaling consistently) was already run and killed in la6 (LA-6.1b-c: no economy-wide rate, < 25% of pair-instances could follow one rate), and conservation of goods in la48. Pivot kept to what is new: a full value vector over 11 goods, scored on equal VALUE between entries of different goods on one document (S1) and between person blocks paid in different mixes (S2), i.e. 'everyone on this tablet got the same wage in different goods'. Web search: no published random search of Linear A value vectors found.
# Data: corpus_ra.json, tablets and lames, read-only numbers, KU-RO/KI-RO lines out, commodity carried down the document; goods with >= 4 documents: *304 AROM CYP GRA MI NI OLE OLIV QA2 VIN VIR. 480 entries, 146 documents, 491 cross-good entry pairs (150 at HT, 19 elsewhere), 62 cross-mix block pairs. Tools: tools/la76_common.py, tools/la76_c1.py.
| LA-76.1.a | 8 random half/half document splits; per split 200,000 value vectors (2,000 random restarts x 100 random proposals, log value in +-ln 60, match = values within 10 %) fitted on the train half; the top 50 re-scored on the test half against the same vectors on 200 test sets with quantities permuted within commodity x site. | Train: top vectors score 3x the random mean (overfit as expected). Test: top 2.89 vs permuted 2.86 (excess +0.02), P <= 0.05 in 0 of 8 splits. Unselected random vectors 2.44. Fitted values do not repeat across splits (SD 0.4-1.3 log units per good; GRA ranges from -1.8 to +1.1). | No hidden value vector carries over to held-out tablets. |
| LA-76.1.b | Planted economy on the real skeleton: true values drawn at random (span ln 20); in a fraction of documents every person block gets one value per document, split over its goods at random, quantity = round(share / value), 5 % noise. Same pipeline, blind. | 100 % of documents planted: excess +2.57, P <= 0.05 in 7 of 8 splits, recovered values rho 0.66 with the truth. 50 % planted: excess +0.72, 2 of 8, rho 0.47. | Power: an economy on all tablets would be found; one on half the tablets is at the edge. |
| LA-76.1.c | No-economy model: quantities drawn independently within commodity x site (one fixed permutation), same pipeline. | Excess -0.02, 0 of 8. | The no-economy model ties with real Linear A: real data loses nothing against it. |
| LA-76.1.d | All goods worth the same (uniform vector) on the test halves against the same permutation null. | Real: excess +2.09, P <= 0.05 in 3 of 8 splits; no-economy model -1.27, 0 of 8. | The only 'balance' in the tablets is equal NUMBERS of different goods (the la6 equal-amount preference), not an exchange rate. Nothing new. |
