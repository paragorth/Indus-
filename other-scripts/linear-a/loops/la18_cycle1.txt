# LA-18 cycle 1: "words that avoid each other" - pairwise anti-co-occurrence of form-related word pairs
Scripts: tools/la18_common.py, tools/la18_c1.py. Output: data/la18/c1_la.json, c1_lb.json (+ logs).
Units: documents with >= 2 distinct word types (>= 2 signs). LA 245 units / 752 types; LB (DAMOS KN, PY, TH, MY, TI, KH) 1,520 units / 3,338 types.
Null: curveball randomisation of the type x document incidence within site strata (keeps every word's document frequency and every document's size exactly); LA 2,000 samples, LB 1,000, LA-sized LB 500.
Form pairs (no sound values): SUF1 w / w+X; PRE1 w / X+w; FIN same length >= 3, last sign differs; INI first sign differs. RND = frequency-matched random pairs with no shared edge sign.
LB truth (sound values used ONLY to label the control): SUF1 adding JO, I, DE, QE, SI, O, PI; FIN with -U/-WE/-WO/-WI or same consonant with vowel change among O, A, I, E.
