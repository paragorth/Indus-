LA-49 cycle 1 (5 Oct 2026). Dissect a machine that learned Linear A: tiny masked-token transformers (inspectable heads) and bidirectional GRUs, random size (d 16-64, 1-3 layers, 1-4 heads), dropout, learning rate, epochs and 80 % train split per seed; tokens = opaque word / logogram identities and 13 log-size number buckets (x fraction flag). 75 models were finished before the cycle was stopped for time (5 tf + 4-6 GRU per corpus; the machine was shared with two other loops at load 16-28). Code: tools/la49_common.py, la49_run.py, la49_report.py; output data/la49_ckpt/c1/report.txt.
Circuits read off each model: F1 attention of masked-number queries to each word type per head; F2 single-head ablation damage on held-out number / word / logogram positions; F3 running-sum test (mask a number, raise every earlier number by two buckets, record the shift of the predicted log value, attribute to the nearest word before/after); F4 cross-seed similarity of word-type representations (RSA) and consensus clusters.
Controls: 3 word-shuffled Linear A corpora (word tokens redistributed over all word slots, numbers fixed); Linear B (DAMOS) and Ur III at Linear A size (5,245 tokens) and Linear B at 4x; a planted corpus (Linear A + 5 real word types made sum-totals on 50 % of multi-number documents, 5 others forced to fixed following numbers).
