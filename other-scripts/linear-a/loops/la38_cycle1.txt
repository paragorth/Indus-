# LA-38 cycle 1: ARE THE BORROWED VALUES BETTER THAN CHANCE? (calibration on Linear B and Cypriot)

|---|---|---|---|
| LA-38.1a | tools/la38_common.py, la38_c1.py, la38_report.py. Prior work: Packard (1974) scored 9 fictitious LA decipherments by LB-like vowel alternations; Davis (2024) scored LA/LB/Cypriot syllabotactic overlap against homomorph relabelings. Neither scores the value map by language-independent phonotactics against grid-preserving relabelings; this does. A value map (sign -> C, V; LB-derived for LA) is scored by 9 measures: ocpC / ocpP (adjacent same consonant / same place class avoided, -log obs/exp), sameV (same vowel, reported only), vinit (pure vowels word-initial: onset principle), son (initial strengthening), freqC / freqV (Spearman of row / column token count vs cross-linguistic inventory frequency), comp (-bits/phoneme of the C/V phoneme stream, plug-in bigram), la21 (AUC of the blind la21 same-row probability for pairs sharing a consonant). Unvalued signs (logograms, *-signs, PA3, AU, cluster signs) break words into fragments; only true word edges count as edges. Nulls (10^5 each): R1 consonant labels permuted among rows and vowels among columns (grid kept); R2a vowels permuted inside each row; R2b consonants permuted inside each column; R3 all (C, V) values permuted among signs. | Full Linear B (KN+PY, 64 valued signs, 27,260 tokens). R3: ocpC z +4.2 (P 1e-5), ocpP +3.0 (0.002), vinit +1.9 (0.02), freqC +1.4, son +0.2, comp 0.0, freqV -1.0, sameV -3.3 (LB repeats vowels: the cluster-spelling vowel copy), la21 +11.6. R2b: ocpC +3.9, ocpP +2.9, vinit +1.9. R2a (vowels inside rows): comp +5.7 (P 1e-5), sameV -3.0, freqV -1.0. R1: freqC +2.4 (P 0.006), all others <= +1.3, comp -1.8. | Measure sets fixed here, before LA was run in full (SEL per tier = z >= 1.64 on full LB): R3 and R2b = ocpC + ocpP + vinit; R2a = comp; R1 = freqC. son, freqV and the a-priori 7-measure composite (ALL7) carry nothing in LB and are dropped from verdicts. (An earlier 2,000-relabeling R3 smoke test had already been run on LA; noted for honesty.) |
