# LA-24 cycle 1: THE CLERK RAN AN APPORTIONMENT ALGORITHM (MDL search over share rules)
Idea: amounts in a list = a total divided by shares (small integer weights), rounded to the units. Each list is coded by an apportionment (rule x grid x share alphabet x unit share u, misses coded separately) and by an adaptive baseline (corpus amount frequencies + list scale + repeat cache); the shorter code wins.
Rules: EXACT (fractions absorb the remainder), FLOOR (D'Hondt-like divisor), ROUND (Sainte-Lague-like), CEIL (Adams-like), HAMIL (largest remainder). Grids 1, 1/2, 1/4 (LA, CONV fraction values), 1, 5, 10 sila (Ur III), 1, 1/60, 1/72 (LB).
Data: 144 LA lists (runs of >= 3 quantities of one commodity, cut at KU-RO/KI-RO; 713 entries, 58 lists with fractions); 100 Ur III ration lists (CDLI ATF, texts with sze-ba, sila3); 113 LB single-commodity line runs (DAMOS). Tools: tools/la24_core.c, la24_common.py, la24_c1.py, la24_c1b.py; checkpoints data/la24_ckpt/c1.json, c1b.json.
No prior apportionment-rule search on Linear A found (LITERATURE.md; web search: Corazza et al. 2021 and "Fractions and food rations in Linear A" assign fraction values to ration texts, but do not search allocation rules).
