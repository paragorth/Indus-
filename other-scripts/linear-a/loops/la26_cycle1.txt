| LA-26.1b | Site level. For 4 measures (shared word types of 2+ signs; syllabic sign-profile 1-JSD; shared logogram ligature variants such as OLE+KI; entry structure as token-class bigram 1-JSD): Z_ij = observed minus the mean under 1,000 document-label permutations within support type (controls size and support), divided by the SD. T = mean distance-residual Z on ring pairs minus on unlinked pairs. Nulls: QAP node relabelling (exact 720 for 6 nodes, 5,000 for 9), curveball rewiring of the seal x site graph (2,000), and the distance-only model built into T. Node sets: A (6 sites in the seal system), B (A + Phaistos, Malia, Tylissos with no shared seal recorded), C (4 sites with >= 50 docs); all documents and administrative documents only. | Nothing passes. Core graph, set A: words T +0.39 (QAP P 0.43, rewire 0.82); signs +2.34 (0.14, 0.45); ligature variants -0.27 (0.63); structure +2.89 (0.17, 0.51). Set B: best signs T +2.11 (QAP 0.058, rewire 0.27); words -0.08 (0.64). Set C: QAP floor 0.25 (24 relabellings), all P >= 0.25. Broad graph (with look-alike): T negative for all 4 measures in every set (QAP 0.66-0.96). Admin only: same pattern. Almost every pair shares FEWER words than permutation predicts (endemism, as in la15). Khania is extreme: sign profile z -11.4 vs HT and -8.7 vs ZA; entry structure z -15.2 vs HT and -17.2 vs ZA. | No effect at site level. The only positive drift (signs, structure) comes from Khania being unlike everyone, and Khania is also the one site with no ring. |
| LA-26.1c | Positive control at Linear A size: m new word types planted on each of the 6 core ring edges (each inserted into a random document at both sites, replacing a word), m = 2, 4, 8, 16, 30 replicates, 100 permutations, QAP. False-positive control: the same number of planted types on random site pairs. | Detection (QAP P <= 0.05): m=2 0/30 (median P 0.27); m=4 0/30 (0.19); m=8 2/30 (0.08); m=16 22/30 (0.04). Random-pair plants: 0/30 at m=2, 4, 8 and 16 (median P 0.46-0.51), so the false-positive control is clean. For scale, the whole corpus has only 22 word types at 2+ of these 6 sites. | **The site-level test has no power at Linear A size.** A ring process that planted 48 shared words (twice the real number of multi-site words) is found in about 7% of runs; detection needs about 96 planted shared types (m=16, 73%), four times the real multi-site vocabulary. The null for LA-26.1b is an upper bound only and cannot rule out ring-mediated vocabulary sharing. |
