la81 cycle 3 (7 Oct 2026): THE COPYIST'S EYE (tools/la81_c3.py)
Idea: a scribe copying a written model by eye keeps its line breaks; one writing from dictation, memory or
receipts re-flows the text. Cycle 1 hinted at it (the same HT word cut at the same sign on two faces).
For every pair of tablets sharing >= 2 sign-groups (sign-groups on > 30 documents excluded), count shared
sign-groups that start a physical line in both. Null: each document's line-start flags permuted within token
class (entry-initial sign-group vs other), 20,000 times, which keeps line density and entry structure.
Prior work: la36 (lists sharing recipients), la69 (drafts vs fair copies by reader independence), la75 (copied
quantities) never used physical line breaks. Web search ('scribes copying layout line breaks preserved
copy detection tablets'): copying of layout is discussed for manuscripts, not tested on Linear A.
