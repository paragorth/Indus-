LA-65 cycle 1: LINEAR A DOSSIERS AS CONTROLLED EXPERIMENTS - find every group of near-copy tablets by random template search (pe63 ported)
Date 6 Oct 2026. Scripts: tools/la65_common.py (corpora, planting, features, search, merge), tools/la65_c1.py (one run),
tools/la65_report1.py (family-wise and FDR thresholds, dossiers, controls). Checkpoints data/la65_ckpt/ (git-ignored, < 10 MB).
Novelty check: la41 searched pairwise near-copies (5 families, 3 of them recto/verso) and la63 noted the HT86/HT95 group;
no earlier loop searched for template SERIES with random templates against matched nulls, or typed slots inside them.
A quick web search finds archive studies of HT deposits (e.g. the HT 27a/89/94a/100 personnel-plus-commodities group)
but no blind dossier search with minimal-pair typing. Their interpretations were not used as input.
Corpus: 246 Linear A administrative tablets (sides and fragments merged; >= 2 entries, >= 1 number). Entry = run of
words/logograms closed by one number. Signs opaque; no Linear B value or role is used for Linear A.

| LA-65.1a | Template search, LA with metadata. A random template = 1-4 features drawn (rarity-weighted) from one random tablet: a word, logogram base, entry, exact entry+number, logogram+fraction, header entry, closing entry, entry-type skeleton, entry count, logogram set, site, scribe, findspot, block of 6 consecutive numbers (2 offsets). Group = every tablet with all features (2-40). Score = HELD-OUT cohesion (mean pairwise tablet-calibrated z of IDF-weighted content similarity after removing what the template defines). 2,000,000 templates per run. NULL: 5 corpora with every entry moved to a random slot of the same site, kind (number/context) and position class (metadata kept). Family-wise threshold = max of all nulls per size class (2 / 3 / 4-5 / 6+) | 2,154 distinct groups; thresholds 15.0 / 7.4 / 7.7 / 4.0; 1 significant group: ZA4, ZA5, ZA15 (score 8.2, template VIN logogram set + Zakros). Each null scored against the other four: 2, 0, 1, 0, 1. Top sub-threshold pairs: HT16~HT20 (13.8, same scribe), HT86~HT95 (12.4), MA4~MA6, HT17~HT19 | Strict level: Linear A has one template series, at the null false-positive rate (0-2). |
| LA-65.1b | Same search with content features only (LAN; no scribe, findspot or numbering, as for Linear B), 5 nulls; also an FDR level (smallest score per size class with mean null count / real count <= 0.2) | Family-wise: 1 group (ZA4/5/15 again). FDR 0.2: thresholds 9.75 / 3.5 / 2.25 / 1.5, 107 groups, merged into 26 dossiers covering 109 tablets, e.g. HT86+HT95+HT120 (GRA, SA-RU, DI-DE-RU), HT16+HT20, HT17+HT19(+KH100), HT38+THE tab.4 (CAP), ZA4+ZA5+ZA15(+PH9) (VIN), HT23/30/32/33/34/35/60 (MI, VIN, QA2, OLE small fractions), MA4+MA6+PH12+PH13 (HIDE), a 17-tablet OLE/OLIV/GRA/*304 group, HT7/10/13/85/122 (DA-RE, PA name lists), HT27/89/94/100/110/130 (CYP + KU-RO; this recovers blind the group that archive studies call personnel-plus-commodities lists) | FDR dossiers are mostly topical groups (same commodities, same site), not copies. |
