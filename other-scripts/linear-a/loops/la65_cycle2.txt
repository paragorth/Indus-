LA-65 cycle 2: inside each dossier, align the copies and type every slot by what changes with it
Scripts: tools/la65_c2.py (alignment, slot typing, coupling and fraction tests), tools/la65_c2b.py (matched random groups).
Slot types: ID = word swaps, logogram base constant (identifier); COM = word swaps with the logogram base (commodity-bound);
GEN = logogram swaps under a constant word; STEP = constant word with a constant-ratio/difference number run over >= 3
members; NUM = constant word, free number; FIX = nothing changes. RATE = two slots in a constant ratio over >= 3 members.
Alignment: order-preserving (Needleman-Wunsch) on shared words, logograms, numbers, fractions and entry type.
