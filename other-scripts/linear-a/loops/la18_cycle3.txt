# LA-18 cycle 3: do ENDINGS avoid each other on a tablet? (case harmony; annealed ending paradigms)
Scripts: tools/la18_c3.py, tools/la18_c3b.py. Output: data/la18/c3_la.json, c3_lb.json, c3b.json. (data/la18/c3_v1_biased/ = first run, discarded: null anneals had half the search effort of the real anneal, which made 2/5 negative controls 'significant'; fixed to equal effort, 3 restarts x 3,000 steps for real and null.)
Statistic: for the top K final signs (LA 12, LB 15 / LA-sized LB 12), C[x,y] = co-present type pairs on a tablet ending in x and y, vs curveball null (site strata; endings travel with their words). Homogeneity = same-ending pairs; partition = annealed split of the endings into g = 2-4 classes maximising standardised within-class excess, calibrated by the same anneal on 200 null matrices.
