la81 cycle 2 (7 Oct 2026): THE ARROW OF WRITING TIME (tools/la81_c2.py)
Idea: a list is written in time. If entries were written as things happened (arrivals, deliveries, a running
procedure) some entry property drifts or cycles in writing order; reversing the list then changes the
statistics. The list-reversal null is exact: each list's direction is flipped at random, which keeps every
list's content and every within-list dependency except direction. Checked first: la20 (pecking order of
items), la53 (earliness of words), and the HT descending-amount finding are about WHICH item comes first,
scored against within-list shuffles; none uses time-reversal asymmetry (trend and cyclic flux). Web search
('arrow of time detection administrative lists entry order entropy production'): nothing on ancient lists.
Units: lists = tablets with >= 6 entries (an entry closes at a number); first and last entries dropped
(headings and totals are positional by construction). Entry properties: first sign, last sign, sign-group
length, amount class, fraction present, logogram present, sign-group frequency in the 1950 lexicon.
Hypotheses: 20,000 random codings (1-2 properties, random partitions into 2-3 states). Statistics: signed
trend of state 0 (sum of centred ranks) and, for 3 states, cyclic flux (0->1->2->0 minus reverse); z under
the exact flip null. Survivors |z| >= 3 on lists published by 1950 (78 HT lists) frozen, scored on lists
published later (21). Controls: whole lottery rerun on direction-flipped training lists (20 runs);
planted drift (in half the lists, long sign-groups pushed later); Linear B KN -> PY and, within Pylos,
series A-E -> F-Z (structural only); commodity coding as a positive.
Bug found and fixed before the verdict: sequences of one state gave trend values of 1e-17 (rounding), which
the flip null cannot move; the first LA freeze (sha256 00e7d51a...) came from that code and was discarded.
