# LA-21 cycle 1: let universals build the grid (blind C x V grid by annealing; scripts tools/la21_core.c, la21_common.py, la21_run.py, la21_report.py; outputs data/la21_ckpt/, git-ignored)
Prior check: LITERATURE.md, FINDINGS.md, STRATEGIES.md: no blind grid built from phonotactic universals (la10 bred languages but spelled them with Linear B values; la5 Kober statistic used LB values). Web: Kober/Ventris grids use inflectional alternation; Corazza et al. 2022 (LT4HALA) cluster Cypro-Greek signs by context + glyph images (no C x V grid, no universals). Not done in this form.
Model (no sound values as input): 65 commonest signs (by word-type count) of each corpus, words cut at rarer signs. Grid = 1 pure-vowel row + 14 consonant rows x 5 columns, <= 2 signs per cell. Score (nats) = tier-factorised bigram log-likelihood (next sign = P(row'|row) P(col'|col) P(sign|cell), word start/end as boundary state on both tiers; harmony or its absence fitted by the column matrix) + OCP (expected minus observed same-row adjacency of distinct signs) + pure-vowel-row initial excess. Simulated annealing, 100k moves per restart (relocate, swap cell, swap row only, swap column only), 400 restarts per corpus (4,000 anneals, 4e8 moves). Metrics: decisiveness and number of sign pairs sharing a row / column in >= 70% of runs (row70, col70); truth scores only for controls (and LA as outside check): AUC of the co-assignment frequency for true same-consonant pairs (cRowAUC: consonant signs only) and same-vowel pairs (colAUC).
