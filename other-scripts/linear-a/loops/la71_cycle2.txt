LA-71 cycle 2: RESTORATION AUDIT, part 2. Every named B result and the la67 clean survivors re-run in three corpus versions: all (= old corpus.json), rd (read + damaged; restored and erased tokens removed), read (read only) (6 Oct 2026)
Method: the original scripts run unchanged through tools/la71_run.py (serves the version's corpus for data/corpus.json, redirects every write to data/la71_ckpt/redir/VERSION/, rebuilds derived caches), or a compact re-implementation where the original needs a bank that is not kept (la58) or is a direct count (totals, basket). Removed tokens stay as placeholders, so a section that loses a number or a section word is untestable, never a miss (la71_totals.py; la70_common sections; la60_common keeps them as 'X'). The 'all' run reproduces each published number first (control). Scripts: tools/la71_run.py, la71_totals.py, la71_basket.py, la71_la58.py, la71_la47.py, la71_la45sum.py, la71_power.py. Results: data/la71_ckpt/c2_*.json, logs/.
