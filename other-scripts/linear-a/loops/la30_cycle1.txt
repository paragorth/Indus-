# LA-30 cycle 1 (4 Oct 2026): THE TOTALS ARE IN A HIDDEN CURRENCY (CONTEXT idea #1), Linear A KU-RO sections.
# Differs from la6 (which fitted pairwise commodity ratios inside entries, never totals): here only written totals constrain
# the rates, every commodity type has a free rate into a common unit, and fraction values are searched jointly.
# Script: tools/la30_c1.py (engine tools/la30_common.py); outputs data/la30_ckpt/c1_*.json (git-ignored).
# Data: 32 KU-RO / PO-TO-KU-RO sections (totals_test.py cutting rule), 15 of them mixing >= 2 entry types; 25 types
# (full logogram, NI, single *NNN, 'bare' = number after a word); only 8 types occur on >= 2 tablets. Fraction letters in
# these sections: A, E, F, H, J, JE, L2. D and B occur in none of the 32 sections (0/32), so totals cannot test D = 1/5, B = 1/3.
| LA-30.1a | Full-corpus fit, plain sum as baseline. Rates on the simple-rational grid p/q (p, q <= 12; half the types left at 1), fraction letters free on 17 values; 2x10^4 random + 16 annealed chains x 300 steps with 'solve one section' moves. Criteria: exact, or 'round' (within max(0.5, 1 %)). | Exact: plain sum 9/32 (3 of 15 mixed); best vector 10/32, the one gain is HT 123+124a #2 (OLIV 93J -> 25H with OLIV = 3/11, i.e. the separate *308 total read as converted olives). Round: plain 13/32, best 17/32 with 17 rates != 1 (NI = VIN = 12, CYP+E = 5, *86 = 11/12, TI+A = 4/9 ...) and J = 2/3, JE = 1/16. | In-sample only: any 25-parameter vector buys a few totals. Not evidence. |
| LA-30.1b | Held-out test (exact): fit on half the tablets, count balanced totals on the other half minus the plain sum; 10 random tablet splits x 4 replicates (8x10^5 random vectors + annealing). Nulls with the identical search: N1 commodity labels shuffled across all entries (24 reps), N2 totals replaced by random integers log-uniform in [T/2, 2T] (24 reps). Planted: random rate vector (half the types != 1) makes every total, 30 % then damaged (12 reps). | Real: train gain +1.2 but held-out gain -1.73 (sd 0.16; mixed sections -1.33): the fitted vectors break more held-out totals than they fix. N1: -2.80 (real > N1, P 0.04, because true labels keep plain sums intact), N2: -0.23 (P real >= N2 = 1.0). Planted: held-out +1.74 (sd 3.2), above the N1 95th percentile in 9/12; planted rates recovered exactly 47/155 (30 %); held-out gain on MIXED sections +0.02. | NO hidden-currency vector balances held-out Linear A totals: the plain sum (all rates 1) beats every fitted vector out of sample. Power is low: at Linear A size even a planted currency gives no held-out gain on mixed sections (only 8 types recur across tablets), so this is a weak negative for 'mixed totals are converted' (grade B for 'no evidence', C for 'no currency'). |
| LA-30.1c | Same as 1b with the 'round' criterion (|S - T| <= max(0.5, 1 % of T)): scribal rounding of converted values allowed. Same nulls and planted control (24 + 24 + 12 reps). | Real held-out -2.75 (mixed -2.60) after train +2.7. N1 -3.46 (P 0.16), N2 +0.03 (P 1.0). Planted +1.81 (above N1 95th pct in 10/12), rates recovered 35/155, mixed-section held-out gain -0.08. | Same verdict: no rate vector transfers to held-out totals; allowing rounding only adds overfitting. Fails before a currency can be tested on mixed sections (planted control has no mixed-section power). |
| LA-30.1d | Occam version of 1b (exact): after each train fit every rate and fraction value not needed for the train count is reset to 1 / its site value, then tested on the held-out half. Same nulls and planted control. | Real held-out -0.30 (mixed -0.23). N1 -0.85 (P 0.12), N2 random totals -0.22 (P real >= N2: 0.60). Planted currency: +3.88 (mixed +1.28), above the N1 95th percentile in 11/12. | CALIBRATED NEGATIVE (grade B): with the planted control now passing (also on mixed sections), real Linear A totals gain no more from a fitted currency than random totals do. A currency affecting several recurrent commodity types in most sections would have been seen; one confined to rare types (17 of 25 occur on one tablet only) would not. |
| LA-30.1e | Occam version with the 'round' criterion (rounded conversions allowed). | Real -1.43 (mixed -1.28); N1 -1.00 (P real >= ... 0.84: real is no better than shuffled labels), N2 0.00. Planted +3.23 (mixed +0.81), above the N1 95th pct in 9/12. | Same calibrated negative: allowing rounding makes real totals fit worse out of sample than random totals. |
| LA-30.1-verdict | Cycle summary | Plain sums are the best predictor of held-out KU-RO totals (exact and rounded); fitted currencies lose 1.7-2.8 held-out totals per half.
