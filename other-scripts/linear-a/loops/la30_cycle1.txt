# LA-30 cycle 1 (4 Oct 2026): THE TOTALS ARE IN A HIDDEN CURRENCY (CONTEXT idea #1), Linear A KU-RO sections.
# Differs from la6 (which fitted pairwise commodity ratios inside entries, never totals): here only written totals constrain
# the rates, every commodity type has a free rate into a common unit, and fraction values are searched jointly.
# Script: tools/la30_c1.py (engine tools/la30_common.py); outputs data/la30_ckpt/c1_*.json (git-ignored).
# Data: 32 KU-RO / PO-TO-KU-RO sections (totals_test.py cutting rule), 15 of them mixing >= 2 entry types; 25 types
# (full logogram, NI, single *NNN, 'bare' = number after a word); only 8 types occur on >= 2 tablets. Fraction letters in
# these sections: A, E, F, H, J, JE, L2. D and B occur in none of the 32 sections (0/32), so totals cannot test D = 1/5, B = 1/3.

Criteria: exact, or 'round' (within max(0.5, 1 %)). | Exact: plain sum 9/32 (3 of 15 mixed); best vector 10/32, the one gain is HT 123+124a #2 (OLIV 93J -> 25H with OLIV = 3/11, i.e. the separate *308 total read as converted olives). Not evidence. |
| LA-30.1b | Held-out test (exact): fit on half the tablets, count balanced totals on the other half minus the plain sum; 10 random tablet splits x 4 replicates (8x10^5 random vectors + annealing). Nulls with the identical search: N1 commodity labels shuffled across all entries (24 reps), N2 totals replaced by random integers log-uniform in [T/2, 2T] (24 reps). Planted: random rate vector (half the types != 1) makes every total, 30 % then damaged (12 reps). | Real: train gain +1.2 but held-out gain -1.73 (sd 0.16; mixed sections -1.33): the fitted vectors break more held-out totals than they fix. N1: -2.80 (real > N1, P 0.04, because true labels keep plain sums intact), N2: -0.23 (P real >= N2 = 1.0). Planted: held-out +1.74 (sd 3.2), above the N1 95th percentile in 9/12; planted rates recovered exactly 47/155 (30 %); held-out gain on MIXED sections +0.02. | NO hidden-currency vector balances held-out Linear A totals: the plain sum (all rates 1) beats every fitted vector out of sample. Power is low: at Linear A size even a planted currency gives no held-out gain on mixed sections (only 8 types recur across tablets), so this is a weak negative for 'mixed totals are converted' (grade B for 'no evidence', C for 'no currency'). |
