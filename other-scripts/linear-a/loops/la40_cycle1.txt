# LA-40 cycle 1: type inference as a compiler does it (pre-registered type rules)
# tools/la40_core.c, la40_common.py, la40_c1.py, la40_report.py; checkpoint data/la40_ckpt/c1.json, c1_report.txt
# Roles: P person/group, L place, C commodity/qualifier, H heading/transaction, T total, M number-word/measure.
# Energy: collapsed Dirichlet-multinomial over 6 structural occurrence features (slot, next token, size of the line's number,
# closure = number equals a sum of preceding entry numbers, line position, previous token) + doc-count bin per type
# + 3 nats per broken type rule (T needs a closing number or the last line; H is not a counted line head and precedes the list;
# C touches a logogram or follows a word; M sits next to a number inside an entry; P/L carry a number or head a phrase)
# + 3 nats per mixed P/L/C entry head on one tablet. P and L have identical rules; L = the one whose words recur on more tablets.
# Tempered Gibbs (T 8 -> 1), 1e6 single-type updates per chain; forced = same role in >= 0.9 of samples and of chain modes.
