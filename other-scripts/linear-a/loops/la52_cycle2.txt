Date 5 Oct 2026. Scripts: tools/la52_run.py (argv kind), la52_c2.py. Report: data/la52_ckpt/c2_report.txt (git-ignored).
Set-up: same features and excess as cycle 1. Gentle regime (bottleneck 75-100 %, noise 0-2 %, memory 600 or all, back-off 0-0.1), 4 generations. Chains of one learner type only: n-gram, slot template, topic-clustered bigram (120 chains each) and GRU (30 chains), each against the same number of shuffled-start chains. Criterion: 'best' = the highest retention any learner type achieves; a structure is a candidate for world anchoring only if even the best learner loses it. Words: pooled long-range retention, best over types, as a z against the 12 words nearest in pooled excess (frequency-matched).
