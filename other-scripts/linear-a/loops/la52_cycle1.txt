LA-52 cycle 1: COPY IT A THOUSAND TIMES AND SEE WHAT REFUSES TO DIE (iterated learning), mixed learners, harsh regime
Date 5 Oct 2026. Scripts: tools/la52_common.py, la52_run.py, la52_report.py. Report: data/la52_ckpt/c1_report.txt (git-ignored).
Novelty check: LITERATURE.md, FINDINGS/STRATEGIES (la46 forgers, r3 grows scripts by iterated learning but fits parameters, it never measures which real structures decay), web search (iterated learning is a language-evolution method; no use on an undeciphered corpus found).
Set-up: corpus -> learner -> new corpus of the same number of documents -> next learner, 6 generations. Learner per generation drawn at random: back-off n-gram (order 1-4, site-conditioned or not), slot-template grammar, topic-clustered bigram (K 2-32), GRU (32/48 units, 4-12 epochs); bottleneck 30-100 % of documents, copy noise 0-8 %, memory 150/300/600/all symbols (forgotten words re-spelled from a sign-bigram model). Linear A 255 documents (sides merged), 3,622 tokens. Feature = relation instance of la46 (sign pair across a word edge, word->number scale, word->logogram, logogram->scale, entry->next entry, co-occurrence, site x word, number->number, running total, first/last word) + ordered logogram pair + word->logogram 3+ tokens later. Excess = documents with the feature minus a kind-preserving shuffle of the same corpus. Retention AUC = mean over generations of (excess(real start) - excess(shuffled start)) / (initial excess - shuffled-start excess); 0 = gone after one copy, 1 = kept.
