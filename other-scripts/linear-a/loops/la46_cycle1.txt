LA-46 cycle 1: HIRE A FORGER AND WATCH WHERE HE FAILS (item-level inversion of the forger contest)
Date 5 Oct 2026. Scripts: tools/la46_common.py (corpora, relations, forger ensemble, contest), tools/la46_c1.py,
tools/la46_report1.py. Checkpoints data/la46_ckpt/c1_*.json.
Novelty check: la14 already ran a DOCUMENT-level forger contest (24 forgers, ~16,000 pairings) and found that
survivors are accounting structure (scale, templates, totals). Web search (forgery/discriminator residue +
undeciphered administrative script) finds nothing. So LA-46 changes the idea: no document-level AUC; instead every
specific relation instance is scored, and the question is WHICH items real tablets keep beating the forgers on.
Corpus: 311 LA documents with >= 4 content tokens (3,622 tokens; sides a/b are separate documents).
Relations (presence per document): XS last sign of word -> first sign of next word; WN word -> log2 scale of next
number; WL word -> logogram within 2; LN logogram -> number scale; ES entry word -> next entry word; CO two word
types on one document, not adjacent; SW site x word; NN number scale -> next scale; TOT word + number = running sum
(>= 2 terms); PF word first / last.
Forgers: 200 random architectures (back-off n-gram order 1-4 over randomly abstracted contexts: rare words merged at
fmin 1-10 or never kept; numbers as log2 bins / 4 coarse classes / kind; logograms exact / base / kind; alpha
0.05-5; optional line index, site, tablet clusters K 2-8 (k-means on tf-idf), copied layout templates, line-reset),
16 groups. 5-fold CV by document, 3 forgeries per held-out document per architecture (~93,000 forged documents
per corpus). Residue p = P(Poisson(E) >= R), R = held-out real documents with the relation, E = forged expectation.
Strict rule: E = max over the 16 groups ('beats every forger'). Liberal rule: E = min over groups (beats the weakest),
calibrated by the null corpora.
Controls (all through the identical pipeline): W1, W2 = worlds written by two forger architectures fitted on all LA
(negative: residues = re-estimation artefacts); SH1, SH2 = LA tokens shuffled globally within kind, layout kept
(negative); PL1, PL2 = forger worlds with 6 planted hidden constraints each (word -> fixed number scale, and a
partner word added on a later line of the same tablet, p 0.8) (positive); LB1, LB2 = DAMOS KN+PY sampled to LA token
count, words as opaque ids; UR1, UR2 = Ur III (CDLI-derived pe38 docs) sampled to LA size. Truth labels for LB/UR
(totals, places, verbs, commodities...) used only to score controls.
