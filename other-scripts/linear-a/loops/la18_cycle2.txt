# LA-18 cycle 2: which ENDING ALTERNATIONS avoid or seek each other? (pairs pooled by alternation class)
Scripts: tools/la18_c2.py, tools/la18_c2b.py. Output: data/la18/c2_la.json, c2_lb.json, c2b.json.
Classes: +X (suffix X added), X+ (prefix added), X~Y (final sign swapped), ^X~Y (first sign swapped); LB >= 5 pairs (full) / >= 3 (LA, LA-sized LB). Class z = (O - E)/sd vs curveball null (site strata), two-sided FWER by max |z| over classes per null row. Context: cosine of context bags (previous/next token class, logograms on the doc, site, support), built only from docs where the partner is absent, vs frequency-matched random pairs (2,000 resamples).
