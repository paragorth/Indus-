# Brief for Claude in Chrome: order CISI scans through Cambridge Scan & Deliver

The user is already signed in to Cambridge University Library (iDiscover / Raven) in this browser.
Do not ask for, type or store any password. If a login or CAPTCHA page appears, stop and ask the user to handle it.

## Goal
Place Cambridge "Scan & Deliver" requests for the sections of the *Corpus of Indus Seals and Inscriptions* (CISI) listed below, to be emailed to the user as PDFs. This is for personal research. Keep to the service rules: one chapter (or at most 5% of the book) per request, and only what is listed.

## Steps
1. Open iDiscover:
   https://idiscover.lib.cam.ac.uk/discovery/search?query=any,contains,Corpus%20of%20Indus%20Seals%20and%20Inscriptions&vid=44CAM_INST:44CAM_PROD
2. Find the records for:
   - **CISI 3.2** (2019; Annales Academiae Scientiarum Fennicae, Humaniora 383; ISBN 9789514111341). Sites: Shahr-i Sokhta, Mundigak, Mehrgarh, Nausharo, Sibri, Dauda-damb, Chanhudaro, Ahar, Balathal, Gilund, Kalibangan, Rojdi.
   - **CISI 3.1** (2010; Humaniora 359; Mohenjo-daro and Harappa, new material).
   For each record, note the holding library (Haddon Library, UL, or other) and the shelfmark.
3. Find each volume's table of contents: in iDiscover, the Haddon/UL record, Google Books, or the publisher's page (https://tiedekirja.fi/en/corpus-of-indus-seals-and-inscriptions-3-2). Note the page ranges of:
   - **3.2: Kalibangan** (plates and catalogue data).
   - **3.2: Chanhudaro** (plates and catalogue data).
   - **3.1: Harappa**, the first section of photographs of the 1986–2007 excavation finds (H-1 onward in the new numbering), if it fits in 5%.
4. Place Scan & Deliver requests, one per item, in this order of priority:
   1. CISI 3.2, Kalibangan section.
   2. CISI 3.2, Chanhudaro section.
   3. CISI 3.1, first Harappa plate section.

   Use the "Scan & Deliver" / "Request scan" option on the item's iDiscover record, or the service pages:
   - https://www.lib.cam.ac.uk/using-library/remote-services/scan-and-deliver
   - https://www.haddon.lib.cam.ac.uk/reader-services/scan-and-deliver

   In the request, give the title, volume, the section name and the exact page range. Ask for **greyscale at the highest available resolution**, because the plates are photographs of carved seals.
5. If a section is longer than the 5% limit, split it into the plates only, or the first plates, and say so in the request notes.
6. If Scan & Deliver is not offered for an item, record why (for example, not held, reference only or special collections), and look for another holding library in iDiscover.

## Report back to the user
A short list, for each item:
- the holding library and shelfmark,
- the page range requested,
- the request confirmation number, or the reason the request failed.

Do not download or open anything unrelated, and do not submit any request not listed above.
