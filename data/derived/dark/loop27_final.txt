# LOOP 27 FINAL: completing the W<->M bridge from aligned object pairs (4 cycles; engine data/derived/dark/loop27_engine.py)
Files: loop27_cycle1.txt (candidate table), loop27_cycle2.txt (hold-out validation), loop27_cycle3.txt + loop27_cycle3b.txt (apply,
reclassify, W34/M95, robustness), loop27_cycle4.txt (tests on the enlarged new set), loop27_candidates.json, loop27_validation.json,
loop27_sets.json (new / added / strict / overlap text ids + the completed bridge), bridge_proposals.json (NOT merged into bridge_extended.json).
Each cycle file ends with its ready-to-paste STRATEGIES.md row (S-DARK-27.1 to 27.4).

## Method
Aligner = loop 24 (Wells seq_raw + lost tokens vs IM77 text, bridge-aware edit distance, site-aware, type/field-symbol compatible, unique best,
cost <= 1 + 0.15 L). Candidate = aligned sign-to-sign (W, M) pair not in the bridge; k = co-aligned distinct text pairs; confidence = Wilson 90%
lower bound of k / (all aligned positions of W); gate: binomial null P < 0.01, k >= 2. Control: wrong-site alignments (1 null pair above lb 0.2,
0 above 0.4; home set 113 / 109). Hold-out: 5 folds of the 142 bridge entries (20% each) removed and recovered.

## Results
1. Validation: 135/142 held-out signs aligned, top candidate right for 132; precision 0.976-0.984 at every threshold, recall 86% (90% of aligned).
   The only 'errors' are W798 -> M53 and W806 -> M389 (the S-DARK-24.1 bridge mistakes, re-found blind) and W711 -> M342 (lb 0.26, removed by
   the threshold). Threshold chosen by rule (precision >= 0.95 and zero null pairs): lb >= 0.35.
2. Proposals: 129 mappings on 129 Wells signs (84 new, 43 Wells splits of an M sign another W covers, 2 corrections); 38 with k >= 5, 52 with k = 2.
   Bridge 142 -> 269 Wells signs, M coverage 138 -> 210; unbridged Wells tokens 17.2% -> 6.5%, uncovered IM77 tokens 13.2% -> 4.3%.
   One-to-many flagged (allograph-level): 45 M signs with >= 2 Wells forms, e.g. M15 = W154/156/158, M245 = W615/617, M253 = W510/511/513,
   M180 = 7 Wells forms, M244 = W630/632/636/643, M375 = W792/808/832, M261 = W625/790/850.
   Contextual, not alignment-validated (listed separately): W34 = M95, the Harappa tablet opener before W700 = M328 (113/177 and 58/64 tokens).
3. Reclassification of IM77 (loop 21 rules unchanged): exact 1,685 -> 1,863, near 157 -> 247, indeterminate 690 -> 308, certainly new 210 -> 324.
   Of the 690 indeterminate: 190 exact, 57 near, 135 certainly new, 308 still indeterminate (254 with W34 = M95; remaining gaps M321, M63, M304,
   M277, M172, M250, <= 12 texts each). 37 former exact matches were wildcard artefacts; 24 former 'new' texts are Wells objects after all.
   New set 324: MD 133, HP 117, Lothal 36, KB 19, CD 9, West Asia 6, other 4; 164 seals, 77 sealings, 43 tablets, 7 copper tablets, 21 pots.
   Added 141: MD 57, HP 56, Lothal 12, KB 9; 69 seals, 29 sealings, 28 tablets, 6 copper tablets; mean 4.4 signs.
   Matcher control 0.1% false exact / 1.3% false near. Robust: k >= 5 proposals alone give 315 new (291 of the 324), k >= 3 give 323.
4. Loop 21 tests on 324 (and on the 141 alone): frame REPLICATED (opener first 13.5% vs 5.2%, opener+connective 32 vs 2.2, closer last 45% vs 16%,
   exclusivity 7 vs 22 P = 0.005); nesting 5.8x / 5.0x; reuse 6.0x (added-only 7.6x); fish 7:2 P = 0.18 (underpowered); names n = 145 seal
   middles 0.98 vs Ur III 0.94 (no separation); quantity type 1 case; minimum lot 5/27 short-1/2 vs 11.6 permuted P = 0.005 (depletion now
   significant, exception rate 18% still above the kill line). No loop 21 verdict changes.

## How much held-out material the bridge completion unlocked
141 more IM77 texts that Wells never transcribed (210 -> 324, +54%; 328 with W34 = M95), i.e. the certainly-new share rises from 7.7% to 11.9%
of complete IM77 texts, and the indeterminate pile shrinks from 690 to 308 (254). 190 (240) indeterminate texts turned out to be Wells objects.
The gain is real but bounded: 77% of the new material is still Mohenjo-daro + Harappa, and the name calibration remains out of reach (145 seal
middles vs the several hundred needed).

## Caveats
- Proposals with k = 2 (52) are validated only through the wrong-site null, not through hold-out (held-out entries are mostly frequent signs).
- The aligner excludes texts < 3 signs and tied candidates, so signs confined to short duplicated tablets (W34/M95) need contextual evidence.
- bridge_extended.json is untouched; the corrections W798 = M53, W806 = M389 are still pending there.
