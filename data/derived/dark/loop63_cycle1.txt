| S-DARK-63.1 | **Logographically written personal names as the comparator for the Indus middle.** All earlier name comparators (Ur III, OB, Linear B, Latin: S-DARK-56) are phonetically written names of inflecting languages with suffixes and a closed edge set. Names written one word-sign per element with free order and no inflection are the right comparator for 'middle = name in word-signs'. Open corpora, one copy per distinct name: modern Chinese given names (wainshine/Chinese-Names-Corpus, Apache-2.0; 1,144,226 full names -> 131,735 distinct given names of 1-2 characters, surname stripped with the repo's 1,074-surname list, gender tag kept; also the full surname+given form), historical Chinese full names (Ancient_Names_Corpus, 254,630, 2-6 characters), Japanese given names in kanji (JMnedict, EDRDG CC BY-SA 4.0: 141,252 distinct fem/masc/given entries, 1-4 kanji; 46,488 'person' full names split by the longest JMnedict surname prefix -> 18,944 distinct given parts; 97,406 surnames), Vietnamese names (UIT-ViNames, 26,850 full names with gender, no licence file so only derived element lists are kept; element = Sino-Vietnamese syllable; 12,265 distinct given names of 1-4 syllables). No openly licensed Korean hanja name list was found (only character inventories), so Korean is absent. The identical S-DARK-56 battery (element TTR / reuse / Gini / Zipf / Heaps; pos_excess, pos_bound; bigram reuse, reversed pairs, adjacent MI, pair predictability, substring share, all minus a within-corpus token shuffle), the S-DARK-56.3d closed-slot statistics (top-10 initial / final / interior coverage, normalised edge entropy, top-10 element share) and the element-level S-DARK-53 capacity statistics, run on Indus middles (S-DARK-26 definition, dedup, >= 2 elements: seq_raw 1,431 / seq_strong 1,403 / seq_all 1,402 / IM77 1,505), on each logographic list drawn 40x at n = 1,431 (also length-matched to the Indus lengths 2-4+ where the list allows: Japanese, Vietnamese, ancient Chinese), on the four phonetic lists, and on frequency-matched random strings built from EACH list's own element unigram and lengths (the per-corpus null).
