LOOP 15 (NEGATIVE SPACE) cycle 1: gaps = patterns the grammar's own generative model expects >= 5 times but the corpus never shows
Script: data/derived/dark/loop15_engine.py ; outputs loop15_c1_<seqkey>.{txt,json} (all texts) and loop15_c1d_<seqkey>.{txt,json} (one copy per distinct text per site and object class)

Model: order-2 Markov chain over whole texts (START START ... END), absolute discounting with Kneser-Ney continuation backoff,
one table per object class (SEAL / TAB / OTHER) shrunk to a pooled table; fitted on Mohenjo-daro + Harappa (home) and, separately,
on the held-out sites (own model).  Expected count of a pattern = mean presence count over 100 synthetic corpora of the same size
and object mix.  Patterns over signs with >= 15 home tokens (105-119 signs; triples over signs with >= 30 tokens, 77-89):
  co   {X,Y} in one text at any distance          ord  X ... Y with >= 1 sign between          skip  X _ Y          tri  X ... Y ... Z, any gaps
Gap: E >= 5 and observed 0 at home.  Controls: (1) each of 100 synthetic corpora scored against the leave-one-out expectation of the
other 99 (how many gaps arise by chance); (2) the home corpus shuffled within each text, model refitted, same search (co gaps are
unchanged by construction, so this control speaks only to ord/skip/tri); (3) held-out sites (842-930 texts): persistent = E_held >= 2
and O_held = 0, with the chance persistence from 20 synthetic held-out corpora.
