S-DARK-34 cycle 1: THE CHECKSUM HUNT, sign targets (3 Oct 2026)
Engine: tools/dark_loop34.py; driver tools/dark_loop34_c1.py (+ dark_loop34_cs.py for the class-sign plant); per-level
logs in the scratchpad (loop34_c1_<level>.txt/json). Data: data/derived/merged-corpus-canonical.json (built from the
older inscriptions.csv, see CLAUDE.md data caution; counts below come from that file) + data/raw/inscriptions.csv
(boss) + data/im77/im77_corpus_lines.csv + im77_field_symbols.csv + data/derived/dark/loop27_sets.json ('new' = the
324 IM77-only texts; 319 with >= 2 readable signs: 162 seals, 77 sealings, 47 tablets, 21 pots, 12 misc; mapped M -> W
through the completed loop-27 bridge, 0 of 1,286 tokens unmapped).

Design. Train = Mohenjo-daro + Harappa seals (1,224 complete, direction-recorded, >= 2 signs). Held-out (a) = seals
from every other site (291); (b) = the 319 IM77-only texts. For each target the predictor sees everything else on
the object: counts of the 120 commonest other signs, the sign before and after the hidden position (40 commonest),
first/last remaining sign, text length, n distinct, n fish, n numerals, numeral-value sum, has opener / marker /
suffix, object sub-type, and ARITHMETIC features (sum of W indices mod 2..13; sum of frequency ranks mod 2..13) so
that a modular checksum is learnable. Models: decision tree (depth 8), random forest (80 trees), 5-NN (cosine).
Labels reduced to the 12 commonest classes + OTHER. Baselines: modal class; slot-grammar baseline = modal class
given the frame class of the rest (opener? marker? suffix? jar present? numeral present? length bucket).
Planted controls through the same pipeline and the same hold-outs: (P1) target := class[(sum of other sign indices)
mod 8] (a checksum); (P2) target := class[rank of first other sign mod 8] over the 40 commonest signs (a class sign
fixed by content); (P3) training labels shuffled. P-values: one-sided binomial of the best model vs the slot rate.

Reading. The machine works: a planted modular checksum is recovered at 1.00 on both hold-outs by the depth-8 tree
(5-NN cannot see it, 0.3-0.4), a planted class-sign lookup at 0.86-0.96, and shuffled labels fall to the modal rate.
No real target comes near either planted level. The gains over the slot baseline are real but small (sites +0.04 to
+0.14, IM77 0 to +0.13) and every carrying feature is a frame rule already in GRAMMAR.md: opener -> connective,
tall-3 / fish -> arrow closer, W550 -> W527, jar elsewhere -> no jar at the end, W590/W705 before the end. The
arithmetic features (sum mod k) never carry a real target; they appear among the top features only with
importances of 0.02-0.03, the level of noise (they are the top features for the label-shuffled runs as well).
Transcription-robust across the three merge levels (all numbers within 0.05).
