Objects: data/derived/merged-corpus-canonical.json (complete, >= 2 signs; seals vs tablets/sealings), depth joined from data/raw/inscriptions.csv by CISI number.
"room" = area-section + block-house + room-grid (Mohenjo-daro house room; Harappa trench grid square). Null = each kin pair replaced by a random same-site pair matched on object type x text length, 1000x.

| S-DARK-29.1 | Same-holder test (a): pairs of complete seals (and, separately, tablets/sealings) at Mohenjo-daro and Harappa in five kinship classes - identical text; same middle (>= 2 signs, S310/S331 parser) + different closer unit; same closer unit (closer + frozen title) + different middle; one-sign substitution (minimal pair, same length >= 3); same emblem with no shared sign (production control). Share of pairs in the same area-section, the same house block, the same room (area + block + room-grid), the same recorded period, and mean |depth difference| (ft; depth from inscriptions.csv by CISI), vs 1,000 draws of random same-site pairs matched on object type x text length; zero counts as < 3/n; seq_raw / seq_strong / seq_all (tools/dark_loop29.py 1) | **Seals: no kinship class predicts the room or the house.** Mohenjo-daro (971 seals, 706 with a room): same-middle-different-closer pairs 18-24, same area 2/17-23 (0.09-0.12 vs null 0.17-0.19, P 0.75-0.91), same block 0/13-16 (< 0.19), same room 0/6-9 (< 0.33), depth diff 6.6 vs 6.1 ft (P 0.68); minimal pairs 193-258: same room 0/117-159 (< 0.02), same area 0.16 vs 0.18 (P 0.76-0.83); same closer + different middle (3,000 sampled): same room 0-1/1,449-1,456 (null 0.001), same area 0.17-0.19 vs 0.19. Identical seal texts (59-75 pairs): same area 0.30-0.32 vs 0.20-0.21 (P 0.02-0.03) but same block 0/40-50 (< 0.075), same room 0/32-40 (< 0.09), depth 6.6-7.0 vs 6.6 ft (P 0.5-0.7). Harappa seals (271): identical pairs 13-15, same grid square 2/6-7 (null 0.015, P 0.007-0.016); same-middle-different-closer 2 pairs (0/1 same square); same-closer-different-middle 4/275-304 same square vs 0.004 (P 0.01-0.016, the Granary/Trench I squares). **Tablets/sealings behave differently:** identical tablet texts cluster at Harappa (same square 0.07-0.11 vs 0.022, same area 0.18-0.20 vs 0.12, same period 0.38 vs 0.32, all P 0.001) and at Mohenjo-daro (same block 9/55 vs 0.038, depth 3.1-3.6 vs 4.7 ft, P <= 0.004); Harappa tablet minimal pairs also cluster (same square 11/192 vs 0.02, same period 0.53 vs 0.37, P <= 0.005); but same-middle-different-closer tablets do not (0/6-16 same room, area P 0.23-0.43). Identical at all three merge levels. | **Null for the holder model on seals; the only spatial kinship is copy-sharing on tablets.** Two seals that share a middle and differ in the closer are found no nearer each other than frequency-matched random seals: 0 of 13-16 in the same house block (< 19%), 0 of 6-9 in the same room, no depth or period match. Minimal pairs and shared closers are equally unclustered. The one seal effect, identical texts 1.5x more often in the same area-section at Mohenjo-daro (P 0.02-0.03), stops at the area level (never the same block or room) and is the S-DARK-12.2(c) stock-copy effect, not co-ownership; at Harappa the 2/6 identical seals in one grid square are the Granary/Trench I stock seals. Tablets with identical texts or one-sign substitutions cluster by square, period and depth (S-DARK-12.4 replicated with a length-matched null), consistent with batch deposition of vouchers. Rests on Mohenjo-daro (18-24 holder pairs) + Harappa (2); same-middle pairs with a known room are only 6-9, so the room-level upper bound is weak (< 33%); the block-level bound (< 19%) and the area-level deficit are the usable results. |
