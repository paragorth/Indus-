# Data note: data/raw/inscriptions.csv carries NO Wells ~a/~b/~c variant letters (0 of 5,680 text fields contain a letter or tilde). The only
# variant structure in the data is the S268 merge classes in sign_allographs_levels.json (23 sets, all levels incl. doubtful, seq_raw) plus the
# five S-DARK-11.3 allograph-like candidate pairs (384/388, 27/28, 525/526, 850/851, 390/407). A finer allograph clock needs a variant-level
# transcription (the CISI allograph set of S22 covers 179 Mohenjo-daro objects only).
# Time axes: depth = ft below datum (sign flipped so larger = later); period = HARP fine period at Harappa (Period 2 < 3B-1 < ... < 5A), Marshall/Mackay
# Early < Intermediate < Late at Mohenjo-daro. Time is residualised on its stratum mean (site x excavation area x object type), so the object-mix confound
# (seals shallower than tablets) cannot enter; permutation 2,000x of time labels across texts within the same strata, tokens inherit their text's label.
# Method correction during the loop: version 1 used raw time; the null was then centred away from 0 (between-stratum component), which made the rows hard to
# read and the shuffled-label control looked like the real data. Residualised time fixed this; only the residualised numbers are reported.
