VERDICT: Null for the script. Every Bonferroni survivor pairs a text-FORM relation (length sum/difference, Jaccard, longest common
substring, identity, shared bigram, closer pair, opener/closer frame class) with object type, completeness/condition, size, or
emblem-vs-no-emblem. These are the three known confounds: (1) tablets and sealings carry a small set of repeated short texts with
fixed closers (identical-text pairs are 94% tablet-tablet; closepair x type z 11.9); (2) broken objects carry truncated texts;
(3) bigger seals carry longer texts. The emblem arrows (closerclass, frameclass x emblem) reduce to the unicorn-format/owner-formula
link already in GRAMMAR.md (S65/S46) plus emblem-less object types. Material/shape arrows below Bonferroni die under the
within-site-x-type null (steatite square = seal). No arrow linking two texts to find-spot (area, room), boss, period, depth or cult
replicated in any cycle, and the ones that did in the scrambled controls (xorsign x period, sharerare x cult: 2, 2, 0, 2 per control)
mark the false-positive rate of the held-out stage on sparse fields (~0.1% of arrows).
SET stage: 1-5 MD hits per cycle vs ~1.2 expected, 0 of 10 replicated at Harappa in the same direction; set x fact correlations
likewise. The MD find-groups are a little more internally repetitive than a within-site x type re-deal (same-middle-different-closer
pairs 3.7% of groups vs 0.3% null), consistent with house-level clustering (S62/S63) and tablet hoards; Harappa shows the same raw
value with an equally high null. Outside MD+H only 2 find-groups of >= 3 objects exist, so the set test cannot be replicated on
held-out sites with this corpus.
