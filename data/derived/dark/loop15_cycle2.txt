Second null: sign tokens permuted across texts within site x object-class strata keeping text lengths, 200 corpora (E_perm).
A gap is 'robust' when E_perm >= 5 as well as E_model >= 5 (so it is not a misfit of the order-2 chain).
Kinds: REPEAT (X..X), PARADIGM (X and Y never in one text), ORDER (X..Y never with a gap, Y..X attested >= 3),
BOUND (X,Y adjacent >= 3 but never separated), TRIPLE (all three pairs attested >= 3, triple never), REDUCIBLE (a pair is already absent).
