# S-DARK-25 cycle 3: HELD-OUT REPLICATION of cycles 1-2 (fit Mohenjo-daro + Harappa, test the other sites) and arrow accounting
# Tool: tools/dark_loop25.py 3 <level> 200. Tables: loop25_cycle3_seq_raw/strong/all.txt

Design. Hubs (cycle 1) and determinative candidates (cycle 2) are fitted on the 2,751 MD+HP texts only, then tested on the 404
complete direction-recorded texts from the other sites (Lothal, Dholavira, Kalibangan, Chanhu-daro, Nausharo, Banawali, ...).
Test 1: attachment rate = share of held-out host tokens that carry their fitted hub on the fitted side, vs the stratified token
shuffle (site x object type x length, 200x) and vs the frame-kept (within-slot) shuffle. Test 2: for every fitted hub, held-out
attached vs free tokens. Test 3: determinative candidates re-derived at the other sites (minn 12) with the same cuts; loyalty.

Results (seq_raw / seq_strong / seq_all)

Arrow accounting. Cycle 1: 3 corpus-level statistics x 3 levels (all P = 0.005, floor of 200 perms; the null is trivial, so these
carry no weight) + per-hub descriptives. Cycle 2: 39 candidates x 2 tests x 3 levels = 234 comparisons; the only hits are the
coherence z's, which the frame-only planted corpus shows to be frame signals; loyalty: 0 of 234. Cycle 3: 2 attachment-rate
tests x 3 levels, P = 0.005 each, Bonferroni over 6 still < 0.05; the P floor is 1/201. Total arrows fired this loop ~ 260; the
only replicated positives are the frame attachments already in GRAMMAR.md (jar after titles, W2 after openers, numeral + tree,
705-33), which this loop did not set out to find.

Sampling caveats. The held-out set is 404 texts (13% of the corpus); a 3-host hub needs >= 7 host tokens there, so W407, W400,
W33 are 'not replicated' at < 3/7-10, an upper bound. All complement and determinative absences are upper bounds: the planted
corpus shows the detector recovers 4 of 12 complements (the frequent ones) and 3 of 3 determinatives with 10 hosts each; a
complement rate < 0.3 per word-sign or a determinative on words with < 2 tokens would be missed at this corpus size.
