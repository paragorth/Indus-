# Arrow-in-the-dark loop 5: signs as NUMBERS or VALUES. Final summary (5 arms, 22 real arrows; all null).
Method (tools/dark_loop5_engine.py, dark_loop5_cycle.py, dark_loop5_weights.py): simulated annealing, 30 restarts x 1,500 steps,
integer values 1-12 on the 60 commonest non-numeral signs + an OTHER slot; numerals fixed at their S204 stroke values; W2 and W31 unvalued.
Combination rules: sum, product (log-sum), positional base-10. Score = Spearman on held-out sites of the best-train restart (and best of 30).
Controls per arm: outside quantity permuted across objects; sign identities shuffled across the corpus with lengths kept; planted synthetic
target (random true values + noise) to show the annealer can recover a signal; fixed rule 'font-skeleton stroke count = value' (S204 extension;
stroke estimator reproduces W1=1, W3=3, W33=3, W35=5). seq_raw / seq_strong / seq_all for the sum rule (merges never changed a verdict).

Planted controls: recovered held-out rho 0.21 / 0.34 / 0.27 / 0.12 for truths 0.25 / 0.41 / 0.28 / 0.15; assigned values rho vs truth 0.56 / 0.23 / 0.17 / 0.44.
So the annealer finds additive signals of rho >= 0.25 when they exist; none exists.
Stability: no sign's value agrees in > 80% of the top-10 restarts in any real arm (0/60); W740 is 'stable' only in the weight arm and equally so in the shuffled corpus.
Stroke-count = value: near zero everywhere once text length is removed (test rho -0.09, -0.05, 0.01, 0.0; weight hit rate 0.23 vs 0.27 for shuffled).
Correction for arrows fired: 22 real arrows, nominal best single held-out rho 0.24 (thickness, seq_all) which fails its own corrected re-test; with 22 arrows a
max null rho of ~0.2-0.3 at n = 53 is expected by chance alone.
Caveats: 76% of texts are Mohenjo-daro + Harappa, so held-out sets are small (42-309); arm 2 rests on Harappa alone; the stroke estimator is a font skeleton,
not the carved glyph; the merge levels (S268) did not change any verdict.
Lesson for the dictionary: 'all-positive sum of sign values' is a text-length detector (rho 0.36-0.38 with seal area, 0.26 with thickness); any future numeric
reading must beat the all-ones assignment on held-out sites. The S93 text-count link is lexical, not arithmetic.
