THE RECOVERED FUNCTION, in words, for the strongest target (the closer / last sign):
  if tall-3 (W33) or the plain fish (W220) stands before the end and the jar is absent -> the last sign is the arrow W520
      train 23-24/24 and 15/16; held-out sites 2/2 + 3/4, IM77 4/4 + 3/3 (bounds < 3/4 and < 3/3)
  if W550/W555 stands before the end -> the closer is W527 (12-16 train; held-out 4/4, < 3/4)
  if W100 stands before the end -> jar (40/40 train, but 16/19 held-out: a tendency)
  otherwise -> jar (the modal class); nothing else is predictable.
  No rule of the form 'closer X -> emblem Y' or 'middle contains Z -> no numeral' exists at precision >= 0.85 on
  >= 10-15 training seals; the rule census (cycle 4) finds 0 rules for the last sign, 0 for the first sign, 0 for the
  emblem that survive, and for material / shape exactly as many 'survivors' as the shuffled-label census (base rates).

NUMERIC CHECKSUMS: the numeral's value matches no simple function of the text above chance (n signs, n+1, n distinct,
n fish, sum mod 10 / 7 / 9: exact-match rates 0.08-0.18 vs nulls 0.10-0.20); an annealed additive sign-value map
scores -0.02 to +0.04 held-out (permuted-value anneals -0.03 to -0.22; planted truth 0.79 -> recovered 0.72); the
only correlate is text length, NEGATIVE (rho -0.11 pooled, -0.35 on IM77): long seal texts carry the frozen tall-2
terms, short texts carry the 3-8 counts (S216-S217). Same at all three merge levels.

VERDICT. The pipeline recovers a planted modular checksum at 100% and a planted class sign at 86-96% on both
hold-outs, and falls to the modal rate on shuffled labels. On the real seals no target comes within 40 points of the
planted level; the gains over the slot-grammar baseline (0-14 points) are carried entirely by rules already in
GRAMMAR.md (opener-connective pairing, the ten closer units, the W705 + tall-3 term). Emblem, material, boss and
shape are independent of the text (S15/S28/S365 re-found with a supervised learner), and the text is independent of
them. The stroke numeral is not computed from the text. THE SEALS CARRY NO REDUNDANCY BEYOND THE FRAME: what is
predictable is the grammar (which slot follows which), and what it encodes is slot membership, not a check on the
content. This is consistent with an owner-legend system (name + title + closer) and inconsistent with a designed
code that protects its payload. Caveats: the hold-outs are small for rare closers (2-4 cases, bounds < 3/4); the
IM77-only emblem set is dominated by 'no field symbol' seals; 76% of the training texts are MD + Harappa by design.
What would overturn it: a new find set (>= 100 seals, e.g. Rakhigarhi) on which any hidden slot is predicted above
0.9 by a model trained here.
