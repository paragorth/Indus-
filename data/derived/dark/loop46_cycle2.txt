Model: per text, label per usable class present (1 = non-head form), classes absent = missing; K-component Bernoulli mixture, EM (8 restarts, Beta(1,1) smoothing), K = 1..4 chosen by 5-fold held-out log-likelihood. Only texts with >= 2 labels inform K (244 at level all). Null for Delta LL(K=2 - K=1): labels permuted within site x type, 100 shuffles with the same folds. Pools and results:
  POSITIVE CONTROL, all sites pooled (the city dialect of S-DARK-14.2 should appear as K >= 2): best K = 1, Delta(2-1) = -1.6, null -0.6 +/- 2.1, P 0.65. The model does not recover even the known city split from 244 two-label texts.
  Mohenjo-daro all types (118): K = 1, Delta -0.5 (P 0.31); MD seals (103): K = 1, Delta -0.2 (P 0.18)
  Harappa all types (86): K = 2, Delta +0.7 (P 0.19); Harappa seals (44): K = 2, Delta +1.6 vs null +0.1 +/- 0.7 (P 0.020; hand sizes 7 / 37; hand0 prefers 706, 711, 817 and 803, hand1 prefers 405, 806, 877); Harappa tablets (40): K = 4 by a hair, Delta(2-1) +0.2 (P 0.53); other sites (40): K = 1
  Hand locality (K = 2 forced, hard assignment, hand labels permuted within site x type 1,000x): area-section P 0.13-0.43 everywhere except Harappa tablets (MI 0.53 vs 0.27, P 0.009, n 25, hands of 37 vs 3 texts); room-grid P 0.18-0.64; period P 0.38-0.86; material P 0.16-0.62; type P ~ 1 (strata).
  Hand x first sign: pooled P 0.001 (city dialect + openers 861/817), within cities P 0.13-0.44. Hand x last sign: P 0.007 (MD), 0.002 (Harappa), 0.026 (Harappa seals), 0.026 (Harappa tablets), 0.146 (MD seals). Distinct closers per hand not reduced (P 0.08-0.73).
  The hand x last-sign link is cycle 5's context effect seen from the other side: the classes whose form is set by the following sign (717 before the jar vs 711 before 33; 803 before the jar vs 806 before 154; 390 before 2 / 740) make any clustering on forms a clustering on closers.
