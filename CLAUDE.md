# Standing instructions for Claude in this repository

- **Target (user, 4 Oct 2026): Proto-Elamite, Linear A and the Voynich manuscript**, in `other-scripts/`. The Indus work is finished; do not work on the Indus script unless the user asks.
- **Keep digging. Do not stop to wait for the user's reply.** When a strategy finishes, log it and start the next one. Report progress in short lines, and only stop when the user explicitly says stop.
- Every strategy gets a control and a verdict row in `other-scripts/<script>/STRATEGIES.md`, inserted before its "## Summary" section. Keep `other-scripts/<script>/FINDINGS.md` and `other-scripts/SUMMARY.md` current. Say "cracked" only if a reading passes calibrated controls and predicts something outside the corpus.
- **Strategies must be new and counter-intuitive (user, 4 Oct 2026).** Do not use the standard decipherment moves (Linear B or other cognate-script analogies, place-name anchors, formula variants, sign-shape mapping, cipher-family searches, label studies) or anything that 'sounds like the right way'. Use the opposite: lateral, bizarre, arrow-in-the-dark ideas that spend a lot of compute, including massive random guessing (thousands of random hypotheses scored automatically, survivors re-tested on held-out data), each with a planted or shuffled control that could kill it. Run loops endlessly: when one finishes, log it and launch a stranger one. Before running one, check `other-scripts/LITERATURE.md`, the script's FINDINGS.md and STRATEGIES.md, and a quick web search; if it has been done, drop it.
- **Voynich working assumption (user, 4 Oct 2026): the text carries meaning and the goal is to extract it.** The hoax, gibberish, asemic and mechanical-generator readings are well known; do not spend loops confirming them. Treat generator-like statistics as an encoding surface to get through, and aim every Voynich loop at pulling meaning out (what carries information, what it refers to).
- Leeway: guesses are allowed. Grade each working reading A (established), B (likely) or C (guess, with a "would support / would kill" line), and demote guesses that fail.
- Rules of evidence: use data and symbols from anyone, but not other people's interpretations. Commit and push to branch `claude/indus-script-dictionary-u3dzf8`.
- Do the digital legwork yourself, and for records and literature go to Cambridge first (user, 4 Oct 2026): Cambridge University Library (iDiscover catalogue), Cambridge Digital Library (cudl.lib.cam.ac.uk, open), Cambridge Core open-access items and the Apollo repository (repository.cam.ac.uk). Then CDLI, lineara.xyz, DAMOS, voynich.nu transliterations, archive.org, HathiTrust API, Crossref, Wikimedia Commons, headless Chromium (the proxy CA is installed in ~/.pki/nssdb; for sites that refuse curl, run Chromium non-headless under xvfb-run and screenshot pages with `#page=N&zoom=200`; see tools/pdf_page_shot.py, usage: xvfb-run -a python3 tools/pdf_page_shot.py URL PAGE ZOOM out.png). Ask the user only for things that need a human (logins, CAPTCHAs, physical access), and then give a direct link.
- Never disable TLS verification, never click through CAPTCHAs, never put model identifiers in commits. Licensed or paywalled PDFs stay in the scratchpad, never committed.
- Sampling: each corpus is a small fraction of what was written. Report 'never/0 of n' as an upper bound (< 3/n) and do not treat absence of a sign or word as evidence it did not exist.
